## 题目原文

> 请对目标AI应用平台进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

首页 307 到 `/apps`。页面是 Dify 的 Next.js 前端。`/app/web/package.json` 的版本是 `1.9.2`，同目录下的 Next.js 是 `15.5.6`。`/console/api/setup` 返回的仍是这套前端 HTML，Python API 没有挂在这个端口上。前端配置里的 API 地址是 `http://127.0.0.1:5001`。

### 关键观察

`POST /apps` 会处理 React Server Components 的 multipart 载荷。三个表单字段都在时，服务端会执行载荷里的 `_prefix`，再把结果放进响应头 `x-action-redirect`。字段 `2` 缺了的时候，响应只有数字 `digest`，命令没有跑起来。

### 利用链

向 `/apps` 发送带 `Next-Action: x` 的 multipart。字段 `0` 是带 `_prefix` 的对象，字段 `1` 是 `"$@0"`，字段 `2` 是 `[]`。`_prefix` 用 `child_process.execFileSync` 执行 `cat /challenge/flag.txt`，并把标准输出做成 base64 放进重定向地址。

从 `x-action-redirect` 里取出 `a=` 后面的内容再解码，就是 flag。本次是 `flag{2bf4ebb2-3613-422c-942d-e5bc2e433488}`。平台接受。

### flag 位置

`/challenge/flag.txt`。前端页面和 `package.json` 里都没有 flag。
