## 题目原文

> 请对目标远程登录服务进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

容器只开了 23 端口。连上去是 Debian 的登录提示，主机名是容器 ID，协议是 telnet。

### 关键观察

登录名和口令都是 `root`。进去之后的 shell 就是 root，工作目录是 `/root`。

### 利用链

对 telnet 协商字节作出应答后，发送用户名和口令，再读 flag 文件：

```bash
T=$(head -1 .target)
# 登录 root / root 之后
cat /challenge/flag.txt
```

本次正文是 `flag{73b7b7d4-be64-41ae-bcd3-e576cb7f8a1f}`。平台接受。

### flag 位置

`/challenge/flag.txt`。横幅和登录提示里没有 flag。
