## 题解

### 入口与指纹

`Apache/2.4.25` + `PHP/5.6.40`，页面标题 `Welcome to Springfield's Vault!`，只有一个
「Vault's Password」输入框，POST 到 `index.php`。

密码错误时页面回 `Incorrect Vault Password`；传数组（`password[]=x`）会打印两条
`md5() expects parameter 1 to be string` 警告，说明服务端用的是 `md5($password)` 加 `==`
比较。

### 关键观察

PHP 的 `==` 在比较两个「0e + 纯数字」字符串时会当成科学计数法（都等于 0）。
预置的 md5 显然也是 `0e...` 形态（或直接与 `0` 比较），于是任何一个 magic hash 密码都能通过。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -X POST --data-urlencode 'password=240610708' "http://$T/index.php" \
| grep -o 'flag{[^}]*}'
# flag{...}
```

`QNKCDZO`、`aabg7XSs`、`aabC9RqS` 同样有效。

### flag 位置

登录成功后的页面正文。它不在源码或注释里。

## 复盘

- 报错泄漏函数名：`md5() expects parameter 1 to be string` 直接告诉我们比较的是 md5。
- 看到 `md5`/`sha1` + PHP 5.x，先试 magic hash（`240610708`、`QNKCDZO`），一次请求就能验证。
- `password[]=x` 这类数组传参既能触发警告、也能顺带确认后端语言与函数。
