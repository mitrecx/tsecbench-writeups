## 题目原文

> 下载附件，里面是一个二进制程序 packed。直接翻它的字符串一无所获——它被加壳了。脱掉这层壳，找出藏在里面的 flag。注：本题 flag 保留原始格式 HTB{...}，非平台默认 flag{}。

## 题解

### 入口与指纹

`rev_packedaway.zip` 里的 `packed`：ELF 64-bit，statically linked，**no section header**。字符串里有：

```text
$Info: This file is packed with the UPX executable packer http://upx.sf.net $
$Id: UPX 4.22 Copyright (C) 1996-2024 the UPX Team. All Rights Reserved. $
```

文件尾的 `UPX!` 头标明 `linux/amd64`。

### 关键观察

压缩体内已经能看到被切碎的 `Hr3t_0f_th3_p45}` 和 `5w0rdogreen`，但不是完整 flag。`upx -d` 解出 17792 字节、带节区、未 strip 的 ELF。脱壳后的字符串里有一枚完整的：

```text
HTB{unp4ck3d_th3_s3cr3t_0f_th3_p455w0rd}
```

旁边还有一条被重复片段污染的 `HTB{unp4ck3dr3t_HH0f_th3_pH0f_...`，那是壳数据的残留，不是第二枚 flag。

### 利用链

```bash
upx -d -o unpacked.bin packed
strings -n 8 unpacked.bin | grep '^HTB{'
```

### flag 位置

脱壳后的只读字符串。提交 `HTB{unp4ck3d_th3_s3cr3t_0f_th3_p455w0rd}` 通过。
