## 题目原文

> 下载附件，里面是一段 RSA 加密脚本 source.py 与输出 output.txt。作者对 RSA 的「基础常识」似乎有点误解——分析后解密出 flag。注：本题 flag 保留原始格式 HTB{...}，非平台默认 flag{}。

## 题解

### 入口与指纹

`crypto_primary_knowledge.zip` 含 `source.py` 和 `output.txt`。脚本：

```python
n = math.prod([getPrime(1024) for _ in range(2**0)])
e = 0x10001
c = pow(m, e, n)
```

`2**0` 是 1。`n` 是单独一个 1024 位素数，不是两个素数的积。`output.txt` 给出这个 `n`、`e=65537` 和 `c`。`n.bit_length()` 为 1024。

### 关键观察

模数是素数时，`φ(n) = n-1`，私钥 `d = e^{-1} mod (n-1)`，明文 `m = c^d mod n`。不需要分解。

### 利用链

```python
d = pow(e, -1, n - 1)
m = pow(c, d, n)
print(m.to_bytes((m.bit_length() + 7) // 8, "big"))
```

### flag 位置

解密结果就是 `HTB{0h_d4mn_4ny7h1ng_r41s3d_t0_0_1s_1!!!}`。能解出可读 flag，同时证明 `n` 确实是素数：若 `n` 是合数，用 `n-1` 当欧拉函数不会得到这段明文。
