# g-19 · 探索记录

对应题解：[`g-19.md`](./g-19.md)

## 目标与起点

题面说 key 经过一串可逆变换后和常量比较。先把 `top.v` 和交互端口分开。

## 过程

1. `container_addr` 有两个：`*:80` 和 `*:1337`。80 不是 zip，而是 nginx 的 `Index of /`，只有 `top.v`（531 字节）。
2. 1337 先吐一整屏 ASCII 画，最后停在 `Please input your key` 和 `>`。格式写在画框里：`0x` 加 16 个十六进制字符。
3. 按 Verilog 从 `lock` 的比较常量往回推。加法用十进制 `12345678`，不是十六进制。字符串 `"HACKERS!"` 按字符从高字节排。
4. 左移的逆：先看异或之后的值低 5 位是不是 0。是 0，所以存在唯一的 `tmp1`。这个 `tmp1` 又恰好完全落在 `& 0xF0F0...` 的掩码里，所以被掩码清掉的那些位可以全取 0，key 唯一。
5. 把 `0x00e0102030604060` 发过去，同一行后面就是 `flag{...}`。提交通过。

## 排除项

没有把 `<<<` 当成循环左移。低 5 位为 0 说明普通左移就够，循环左移会多出一组解。判据是本地把 key 再跑一遍四级运算，结果等于 `64'h5443474D489DFDD3`，并且服务接受。
