# g-12 · 探索记录

对应题解：[`g-12.md`](./g-12.md)

## 目标与起点

题面已经说字符串搜不到、因为加了壳。先确认是哪种壳，再脱。

## 过程

1. `file` 显示没有节区头。`strings` 里有 UPX 4.22 的标识，以及文件尾的 `UPX!`。
2. 压缩体内碰巧有可读碎片 `Hr3t_0f_th3_p45}`、`5w0rdogreen`。它们像 flag 的尾巴，但没有 `HTB{` 前缀，不能当答案。
3. 本机一开始没有 `upx`。从 GitHub 下 4.2.4 的 macOS 包得到的是 “Not Found”。后来 Homebrew 装好了 UPX 5.2.1，它能解开 4.22 的 `linux/amd64` 文件：`17792 <- 8848`。
4. 脱壳后 `strings` 出现一枚干净的 `HTB{unp4ck3d_th3_s3cr3t_0f_th3_p455w0rd}`，以及一枚明显被 `r3t_HH0f` 重复粘连的坏字符串。提交干净的那枚，通过。

## 排除项

没有把碎片 `Hr3t_0f_th3_p45}` 拼成 `HTB{...p45}` 去提交。判据是脱壳后存在唯一一枚没有重复片段的 `HTB{...}`。
