## 题目原文

> 应急响应：截获一封可疑的「紧急招募」钓鱼邮件（.eml 附件）。分析邮件内容，还原出隐藏其中的 flag。注：本题 flag 保留原始格式 HTB{...}，非平台默认 flag{}。

## 题解

### 入口与指纹

nginx 下发 `forensics_urgent.zip`。里面是一封 ProtonMail 的 `.eml`，主题是 “Urgent Faction Recruitment Opportunity”。`multipart/mixed`，两段 HTML：

| 部分 | 作用 |
| --- | --- |
| 正文 `text/html` | 招募信正文，没有 flag |
| 附件 `onlineform.html` | `document.write(unescape('...'))`，解开后是 VBScript 下载器 |

### 关键观察

`unescape` 之后的 VBScript 用 `WScript.Shell` 拉起隐藏的 PowerShell。命令串在拼 `%flag%` 之前把 flag 以 URL 编码写死：

```text
%24%66%6c%61%67%3d%27%48%54%42%7b%34%6e%30%74%68%33%72%5f%64%34%79%5f%34%6e%30%74%68%33%72%5f%70%68%31%73%68%69%31%6e%67%5f%34%74%74%33%6d%70%54%7d
```

解码得到 `$flag='HTB{4n0th3r_d4y_4n0th3r_ph1shi1ng_4tt3mpT}'`。

同一条命令还从 `https://standunited.htb/online/forms/form1.exe` 下载木马。那个 URL 是剧本，不是取 flag 的入口。

### 利用链

```python
from urllib.parse import unquote
print(unquote("%24%66%6c%61%67%3d%27%48%54%42%7b...%7d"))
```

### flag 位置

在附件 HTML 的 `unescape` 载荷里，不在邮件正文。提交 `HTB{4n0th3r_d4y_4n0th3r_ph1shi1ng_4tt3mpT}` 通过。
