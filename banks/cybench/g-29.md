## 题目原文

> 应急响应：一台主机疑似被植入远控木马。给你一份网络抓包 capture.pcap，请分析木马与 C2 通信，还原被窃取/下发的信息，拼出完整 flag（分三段藏在流量里）。注：本题 flag 保留原始格式 HTB{...}，非平台默认 flag{}。

## 题解

### 入口与指纹

`forensics_data_siege.zip` 里是 pcapng。主机 `10.10.10.21` 与 `10.10.10.22` 之间有四段流量：

1. TCP 61616：ActiveMQ OpenWire。客户端发来 `ClassPathXmlApplicationContext` 和 URL `http://10.10.10.21:8080/nBISC4YJKs7j4I`。
2. HTTP 8080：返回 Spring XML，bean 是 `ProcessBuilder.start`，命令用 PowerShell 下载并执行 `http://10.10.10.21:8000/aQ4caZ.exe`。
3. HTTP 8000：那个 exe，.NET 4.8 的 `EZRATClient`。
4. TCP 1234：RAT 和控制端的会话。消息格式是 `长度§Base64`。

### 关键观察

exe 的 `#US` 堆里密钥是 `VYAemVeO3zUDTL6N62kVA`。`Encrypt` 的 IL 把一段 13 字节静态数组交给 `Rfc2898DeriveBytes`，那段字节就是 `.text` 末尾补上去的 `Very_S3cr3t_S`。默认 SHA-1、1000 次，先 `GetBytes(32)` 当 AES-256 密钥，再 `GetBytes(16)` 当 IV。明文是 UTF-8。

解开 1234 上的命令和回包，三段分别是：

| 段 | 位置 | 内容 |
| --- | --- | --- |
| 1 | 控制端命令：把一行 SSH 公钥写进 `authorized_keys`，注释就是这段 | `HTB{c0mmun1c4710n5` |
| 2 | 回包里 `type credentials.txt` 的结果，标明 “2nd flag part” | `_h45_b33n_r357` |
| 3 | 随后下发的 PowerShell（UTF-16LE Base64）里，计划任务名标明 “3th flag part” | `0r3d_1n_7h3_h34dqu4r73r5}` |

`rest` 和 `ored` 拼成 restored。
