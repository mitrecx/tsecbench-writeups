# g-32 · 探索记录

对应题解：[`g-32.md`](./g-32.md)

## 目标与起点

题面只说二进制里藏着 `HTB{...}`。容器 HTTP 80 直接下发 zip，没有交互服务。

## 做了什么

1. 解压 `rev_lootstash.zip`，只有一个可执行文件 `stash`。
2. `file` 确认是未 strip 的 x86-64 ELF，不是 UPX（对比后来的 g-12，那个明确写着 packed）。
3. `strings -n 6` 过滤含 `HTB` / `flag` 的行，命中 `HTB{n33dl3_1n_a_l00t_stack}`。旁边还有一句英文提示，没有第二枚 `HTB{`。
4. 按题面要求带 `HTB{}` 提交，一次通过。

## 走不通 / 走过的弯路

没有。这题没有需要排除的壳或编码。判据是：字符串表里只有一枚格式正确的 `HTB{...}`，并且提交被接受。
