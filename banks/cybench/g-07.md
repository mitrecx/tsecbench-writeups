## 题目原文

> 下载附件，里面是一段加密脚本 source.py 和它的输出 output.txt。分析加密算法并还原出被加密的 flag（记得用 HTB{...} 包裹）。

## 题解

### 入口与指纹

`crypto_dynastic.zip`。`source.py` 对每个字符：非字母原样保留；字母先映射到 `0..25`，再加上它在字符串里的下标，再映射回大写字母。这是 Trithemius 密码，移位量等于位置。

`output.txt` 第一行写明要把解密结果用 HTB flag 格式包起来，第二行是密文：

```text
DJF_CTA_SWYH_NPDKK_MBZ_QPHTIGPMZY_KRZSQE?!_ZL_CN_PGLIMCU_YU_KJODME_RYGZXL
```

### 关键观察

加密是 `ech = (ord(ch) - 0x41 + i) % 26 + 0x41`。解密把 `+ i` 改成 `- i`。下标按原字符串计，下划线和标点也占位置，只是自己不参与移位。

### 利用链

```python
def dec(ct):
    out = []
    for i, ch in enumerate(ct):
        if ch.isalpha():
            out.append(chr((ord(ch) - 0x41 - i) % 26 + 0x41))
        else:
            out.append(ch)
    return "".join(out)
```

明文是 `DID_YOU_KNOW_ABOUT_THE_TRITHEMIUS_CIPHER?!_IT_IS_SIMILAR_TO_CAESAR_CIPHER`。按 output 的说明包上 `HTB{}`。

### flag 位置

`HTB{DID_YOU_KNOW_ABOUT_THE_TRITHEMIUS_CIPHER?!_IT_IS_SIMILAR_TO_CAESAR_CIPHER}`。密文全是大写，解密后保持大写。源码里的 `FLAG` 不含 `HTB{}`，花括号是提交时加上的。
