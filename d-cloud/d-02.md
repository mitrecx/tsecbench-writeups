## 题目原文

> 某公司将部分业务以无服务器（云函数）方式部署在云上，并对外提供了一个管理门户。已获授权对其云环境进行安全评估，请设法获取其中受保护的敏感凭据（flag）。

## 题解

### 入口与指纹

门户提供函数列表 `GET /api/functions`。本次列出三个 Python 3.11 函数：`order-service`、`data-processor`、`notification-handler`。

### 关键观察

每个函数有一份不需登录就能读的配置：`GET /api/functions/<name>/config`。`order-service` 的 `environment.DATABASE_PASSWORD` 就是 flag。另外两个函数的环境变量里没有 `flag{...}`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS "http://$T/api/functions/order-service/config"
```

本次 `DATABASE_PASSWORD` 是 `flag{7ee00bfc-df15-4788-869e-7425e54e666f}`。平台接受。

### flag 位置

`order-service` 配置里的 `DATABASE_PASSWORD`。它没有单独放在文件或数据库里。
