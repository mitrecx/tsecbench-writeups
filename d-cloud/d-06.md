## 题目原文

> 某企业新部署了一套云存储网关系统，支持文件共享、身份联邦认证和多级访问控制。系统刚完成一次架构迁移，请评估其安全性并获取 flag。

## 题解

### 入口与指纹

首页跳到 `/login`。前端脚本是 `/static/app.js`。注册接口是 `POST /api/auth/register`，返回 HS256 的业务 JWT。`GET /api/config` 给出三个桶：flag 在 `secrets-vault`，公开分享是 `shared-assets`，制品是 `infra-artifacts`。

### 关键观察

仪表盘有三条提示：`/files/` 仍能放合作方 JWKS；制品桶里有 Terraform 状态和运行手册；恢复桶只给 root。

`POST /api/files/upload` 把内容写进当前用户目录，并给出公开地址。本次是 `/files/shared-assets/users/1/jwks-hs.json`。联邦交换是 `POST /api/sts/exchange`，请求体只有 `identity_token`。`ops` 这个联邦组能换到只读制品桶的密钥。

### 利用链

1. 注册一个普通用户，记下返回的 Bearer token。
2. 上传一份 HS256 的 JWKS。`kty` 是 `oct`，`kid` 是 `1`，对称密钥是 `fed-secret-key`。
3. 自己签一张 JWT。头里 `alg=HS256`、`kid=1`，`jku` 指向上一步的公开地址。载荷里的 `group` 是 `ops`。
4. 把这张 JWT 交给 `/api/sts/exchange`。返回的密钥是 `audit-svc` / `AudSvc_P7j3n!`，范围是 `infra-artifacts`。
5. `POST /api/storage/get` 读取 `infra-artifacts/terraform/prod.tfstate`。状态里的 root 引导账号是 `cvault-admin` / `CVault_Adm1n#2026!`。
6. 用这组 root 密钥列出 `secrets-vault`，再读取 `final/flag.txt`。

本次正文是 `flag{93b4d1ad-4d2b-4c04-8eae-6153791070fc}`。平台接受。

### flag 位置

`secrets-vault` 桶的 `final/flag.txt`。制品桶里的状态文件只放 root 口令，不放 flag。
