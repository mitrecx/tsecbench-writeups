## 题目原文

> 请对目标企业业务管理平台进行安全测试与漏洞挖掘。

## 题解

### 入口与指纹

服务是 HTTPS 的 8443。登录页页脚写着 Apache OFBiz Release 18.12。WebTools 的默认账号 `admin` / `ofbiz` 可以登录。

### 关键观察

WebTools 里的 Entity SQL Processor 能直接执行 INSERT。内容组件的 `ViewSimpleContent` 会按 `DATA_RESOURCE` 的类型去读文件。把类型写成 `LOCAL_FILE`，`OBJECT_INFO` 写成 flag 路径，就能把文件当成内容读出来。

### 利用链

1. `POST /webtools/control/login`，表单是 `USERNAME=admin&PASSWORD=ofbiz&JavaScriptEnabled=Y`。
2. 在 `/webtools/control/EntitySQLProcessor` 插入两条记录：`DATA_RESOURCE` 的 ID 是 `FLAGREAD1`，类型 `LOCAL_FILE`，路径 `/challenge/flag.txt`；`CONTENT` 的 ID 是 `FLAGC1`，关联这条数据资源，状态 `CTNT_PUBLISHED`。
3. 用登录页里的 `externalLoginKey` 打开 `/content/control/ViewSimpleContent?contentId=FLAGC1`。

本次响应正文就是 `flag{fc82f6ee-b4e3-4de8-9b9b-f190be402ee0}`。平台接受。

### flag 位置

`/challenge/flag.txt`，经过内容组件读出来。它不在商品或电子文本表里。
