# f1-05 · 探索记录

对应题解：[`f1-05.md`](./f1-05.md)

## 目标与起点

`HELP` 把目标写明了：`REVEAL` 只有在 guard 被破坏后才给出秘密。`DUMP` 一开始是 `guard=0x00000000`，后面是一块全 0 的缓冲。先量这块缓冲有多大，再试能不能写到它外面。

## 第一阶段：正偏移停在 1024，负偏移能碰到守卫

`COPY 0`、`32`、`64`、`128`、`256`、`512` 写 4 字节都成功，`DUMP` 里看得到 `XXXX`，但 `guard` 仍是 0，`REVEAL` 仍是 locked。

`COPY 1020 ABCD` 成功，`COPY 1020 ABCDE`、`COPY 1021 AAAA`、`COPY 1024 AAAA` 都是 `550 copy failed`。所以合法区间是偏移加长度不超过 1024。缓冲末尾写得到，末尾之后写不到。

`COPY -1 AAAA` 被接受，回显的偏移就是 `-1`。同一条连接上 `DUMP` 的守卫变成 `0x41000000`，`REVEAL` 变成 `250 guard broken, flag:` 并给出 flag。`0x41` 是 `A`，说明这 4 个字节从缓冲前一个字节写起。

## 走不通 / 走过的弯路（留档）

| 方向 | 结果 | 判据 |
| --- | --- | --- |
| 只在 0 到 512 写 | 守卫不动 | `guard` 仍是 `0x00000000`，`REVEAL` 是 `423 locked` |
| `COPY 1024` 及更后面的正偏移 | 被拒绝 | `550 copy failed`，`DUMP` 长度仍是 1050，缓冲本身大约 1024 字节 |
| `COPY 1020` 写 5 个以上字节 | 被拒绝 | 同样 `550`。检查的是终点，不只是起点 |
| `COPY -1 AAAA` | 守卫被写成非 0 | `guard=0x41000000`，`REVEAL` 直接打出 flag |

## 这次真正的收获

长度检查只覆盖了 `[0, 1024)`。守卫放在缓冲前面，所以要用负偏移去写它。写坏之后 `REVEAL` 才返回 flag。
